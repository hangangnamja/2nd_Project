# 개인 프로젝트 기획서: 수집형 턴제 RPG

> 결정된 사항은 이 문서가 기준이다. 구현 중 바뀐 결정은 이 문서에 바로 반영한다.
> 수치 상세(성장표, 적 스탯, 파라미터)는 `StatTable.xlsx`가 기준이다.
> `n`으로 표기한 수치는 테스트하며 정한다.

---

## 0. 개요

- **장르**: 속도 기반 턴제 수집형 RPG (붕괴 스타레일식 행동 순서 + 에픽세븐식 스킬 구조)
- **목적**: 개인 프로젝트 겸 기획자 포트폴리오. 재화 흐름·확률·밸런스의 설계 근거를 문서로 남긴다
- **엔진·플랫폼**: Unity 6, URP 3D, 모바일 가로 화면
- **연출**: 최소화 (역량 밖이므로 시스템과 기획에 집중)
- **범위**: 캐릭터 10명, 파티 컨셉 3개, 기본 스테이지 7개 + 보스 스테이지 3개

- **핵심재미**: 추가할것.
- **반복구조**: 추가할것.
- **화면분위기**: 카툰풍.. 서브컬쳐 느낌 나게
- **타깃유저**: 서브컬쳐 장르에 거부감이 없는 남성향 갸차게임

---

## 1. 개발 순서

1. 데이터(SO) + 저장(JSON)
2. 전투 코어: 행동 순서, 스킬·쿨타임, 피해 공식, 상태효과, 패시브 트리거
3. 편성 → 스테이지
4. 가챠 + 인벤토리
5. 전투원(육성) 화면
6. 시작·메인 화면
7. 보스 스테이지 3개 → 업적 (업적은 후순위)

- 처음에는 캡슐 등 임시 도형으로 전투 시스템부터 검증하고, 모델·애니메이션(대기·공격·피격·사망)은 이후 수급한다

## 2. 화면 구성

| 화면 | 내용 |
|---|---|
| 시작 화면 | DB 사용 금지 → 로그인 없이 로컬 세이브 불러오기 |
| 메인 화면 | 보유 캐릭터 일러스트를 중앙에 표시. UI는 명일방주를 임시로 참고 (포폴 최종본은 자체 레이아웃으로 교체) |
| 전투원 화면 | 보유 캐릭터 목록, 스킬·스탯·무기 확인, 캐릭터·무기 레벨업과 진급 |
| 인벤토리 | 에픽세븐식. 무기는 개체마다 레벨이 달라 개체 단위로 보관 |
| 편성 | 4인 파티 편성 |
| 가챠 | 픽업 배너 + 확률 공시 화면 (기본 확률과 최종 획득 확률 함께 표기) |
| 전투 | 3-11 전투 UI 참고 |
| 업적 | 후순위 |

- 우상단 공통: 재화 표시
- 메인 화면 임시 배치 (Lobby 씬, 명일방주 참고): 좌상단 설정·공지·우편·출석 + 이벤트 알림, 좌측 플레이어 레벨·이름·ID, 가운데 대표 캐릭터 일러스트, 좌하단 이벤트 배너·친구·정보, 우상단 재화(보석·골드), 우측 메뉴(출격 / 편성·전투원 / 모집 / 업적·인벤토리)
  - 지금은 출격·편성(SQUAD)·모집·인벤토리(DEPOT)·전투원(OPERATOR) 버튼만 연결됨 (나머지 버튼은 틀만)
  - 스타일 (임시 그림): 어두운 남색 배경 + 일러스트 뒤 빛·원호, 모서리를 깎은 패널, 메뉴마다 영문 라벨(COMBAT·SQUAD·OPERATOR·RECRUIT·MISSION·DEPOT)
    - 출격 = 어두운 패널 + 하늘색 강조, 모집 = 황금색 패널, 나머지 = 밝은 패널. 일러스트 자리는 실루엣
    - 재화·레벨·이름은 아직 세이브와 연결하지 않은 고정 글자
- 모집 (가챠, 메인 화면의 모집 버튼): 명일방주 모집 화면 배치 참고
  - 화면 전체가 배너: 왼쪽 위 배너 제목, 오른쪽 픽업 캐릭터(일러스트 자리 + ★ PICK UP + 이름), 좌우 화살표·상단 점으로 배너 넘기기
  - 좌상단 뒤로·홈, 우상단 보석(세이브 값), 좌하단 강조 문구·배너 이름·종료 일시·**확률 공시**, 우하단 **1회 진행(보석 100) / 10회 진행(보석 1,000)**
  - 뽑기 버튼 위: **A 확정까지 N회**(위), **S 확정까지 N회**(아래). 세이브의 가챠 카운터로 계산 (배너 공통이라 배너를 넘겨도 같음)
  - 배너 내용은 배너 에셋(`Data/Gacha/`)에서 정함. 지금은 S 7명 각각의 픽업 배너 7개 (이름 임시, 아스트라 = "별빛 아래의 공연", 도발 탱커 = "철벽의 방패", 부활 힐러 = "되살아나는 빛")
  - 배너 위 점은 씬에 놓인 오브젝트라, 배너를 추가하면 `PageDots` 아래 점을 복제해 GachaView의 Page Dots 목록에 넣고 간격 80으로 가운데 정렬
  - 1회·10회 진행 → 뽑기 + 저장 → 결과 연출 (7-4). 확률 공시 화면은 아직 없음 (버튼은 로그만)
  - 지금은 디버그 무료 뽑기 (보석 차감 없음, `GachaRules`에서 끔)
  - 스타일 (임시 그림, 메인 화면과 같은 패널·영문 라벨): 배너 테마색으로 물드는 배경 + 픽업 자리 둘레 원호·표식, 왼쪽·아래 그림자로 글자 가독성 확보
    - 배너 제목 = 큰 흰 글자 + 금색 강조 막대, 픽업 이름표 = 금색 PICK UP 태그 + 어두운 이름 패널, 10회 진행 = 금색 패널
- 스테이지 선택 (출격): 좌상단 뒤로·홈, 하단 탭 **스테이지 / 보스전**
  - 스테이지 탭: 기본 스테이지 1-1 ~ 1-7 노드를 선으로 이은 지도 (권장 레벨 1/10/…/60)
  - 보스전 탭: 보스 카드 3장 (스테이지가 없는 칸은 "준비 중"으로 막힘)
  - 노드·카드를 누르면 우측 상세 패널(번호, 이름, 추천 레벨, 웨이브 수) + **전투 준비** → 편성 화면
  - 목록은 `StageCatalog` 에셋에서 정함
  - 스타일 (임시 그림, 메인·모집과 같은 패널·영문 라벨): 작전 지도 배경(어두운 남색 + 등고선·격자), 좌상단 머리글 OPERATION MAP / 작전 지역
    - 노드 = 어두운 패널 + 하늘색 강조 막대, 번호 크게·이름 작게. 연결선은 얇은 하늘색
    - 보스 카드 = 어두운 세로 카드 + 붉은 강조(BOSS RAID 라벨·사선 띠·아래쪽 붉은 빛) + 옅은 번호 워터마크
    - 상세 패널 = 어두운 패널 + OPERATION INFO, 번호는 하늘색 큰 글자, 전투 준비 = 금색 패널
- 편성 (메인 화면의 SQUAD = 편성 관리 / 전투 준비 다음 = 출격): 4칸에 캐릭터 일러스트(칸을 꽉 채움, 일러스트가 없으면 직군 색 박스) + 레벨·이름 (붕괴 스타레일 편성 화면 참고)
  - 칸을 누르면 오른쪽에 보유 캐릭터 목록(카드 그리드, 카드 위쪽에 일러스트의 머리 부분을 확대해 표시) → 고르면 그 칸에 들어감. 이미 편성된 캐릭터를 고르면 두 칸을 맞바꿈, "비우기"로 칸 비우기
  - 좌하단 **전투 시작** → 지금 편성(왼쪽 칸부터 편성 순서)과 고른 스테이지로 전투. 편성이 비어 있으면 막힘
  - 편성은 바꿀 때마다 세이브에 저장. 보유 캐릭터·레벨도 세이브에서 읽음 (9장)
  - **팀 4개**: 오른쪽 위 팀 탭 1~4로 팀을 바꿔 가며 편성을 따로 저장. 탭에는 번호 + 팀 이름
    - 아래 가운데 입력 칸에서 지금 팀의 이름을 지음 (최대 12자, 비우면 "팀 n")
    - 마지막에 고른 팀을 기억해, 전투 준비 편성 화면은 그 팀으로 열리고 그 팀으로 출격
  - 메인 화면에서 열면 전투 시작 버튼이 없고 뒤로 가면 메인 화면, 전투 준비에서 열면 지금처럼 출격
  - 스타일 (임시 그림, 다른 화면과 같은 패널·영문 라벨): 로비 배경, 좌상단 뒤로 + SQUAD FORMATION / 편성, 위쪽에 팀 탭(TEAM 0n, 고른 팀 하늘색)과 TEAM NAME 입력 칸
    - 편성 칸 = 어두운 세로 카드: 위쪽 직군 색 막대, 왼쪽 위 칸 번호 01~04, 아래 어두운 판에 Lv(주황)·이름. 빈 칸은 하늘색 원 + "편성하기", 고르는 중인 칸은 하늘색 테두리
    - 보유 목록(오른쪽, 팀 탭 아래부터) = 어두운 패널 + OPERATORS / 보유 캐릭터, 카드는 어두운 바탕 + 위쪽 직군 색 막대 + 편성 중이면 금색 "편성 중" 배지. 목록이 열리면 편성 칸 줄이 왼쪽으로 비켜 섬
    - 전투 시작 = 오른쪽 아래 금색 패널
- 전투원 (메인 화면의 OPERATOR, 에픽세븐 영웅 화면 참고): 목록 화면 없이 한 화면에서 보유 캐릭터를 넘겨 봄
  - 오른쪽: 보유 캐릭터 세로 목록 (일러스트 머리 + 이름 + Lv·★, 등급 S 먼저 → 레벨 높은 순). 고른 칸은 왼쪽으로 튀어나오고 하늘색 막대
  - 가운데: 큰 일러스트 (없으면 직군 색 실루엣), 옆에 무기 칸 1개 (낀 무기 아이콘·등급 테두리·Lv·이름, 없으면 + 와 "미장착")
    - 무기 칸을 누르면 **무기 장착 창**: 왼쪽에 이 캐릭터가 낄 수 있는 무기 칸 목록(낀 무기 → 등급 → 레벨 순), 오른쪽에 고른 무기 정보 + **장착 / 해제 / 강화**
    - 다른 캐릭터가 낀 무기를 고르면 "가져와 장착" (그 캐릭터에게서 빠짐). 강화는 육성 창을 무기 모드로 엶
  - 왼쪽: 탭 **상세 / 스킬** + 정보 패널 (직군·이름·★·Lv / 60·진급 ◆◇ 5칸)
    - 상세: 공격력·방어력·생명력·속도·치명 확률·치명 피해 (전투와 같은 레벨·진급 배율 + 무기). 무기 몫은 숫자 앞에 초록 +n
    - 스킬: 1~3스·패시브·변신 스킬·종결기 효과 (전투 상세 창과 같은 자동 설명)
  - 아래: **레벨업** 버튼 → 육성 창. 레벨 상한(10·20·…·50)이면 같은 버튼이 **진급**, Lv60이면 "최대 레벨"
  - 육성 창 (젠레스 존 제로 에이전트 육성 참고): HP·공격력·방어력 지금 값 + 오를 값, 경험치 바(지금 레벨 → 도달 레벨, 경험치 / 필요량), 경험치 재료 3칸
    - 재료 칸을 누르면 +1, 홀드하면 연속 추가, 빨간 − 로 빼기. **전부 제거 / 일괄 추가 / 레벨업**
    - 일괄 추가: 다음 진급 레벨(상한)까지 필요한 만큼 큰 재료부터 채움. 상한을 넘는 경험치는 버림 (힌트 줄에 버려지는 양 표시)
    - 진급: 상한에 닿으면 같은 창이 진급 화면(진급 n → n+1, 최대 레벨 변화, 오를 스탯)으로 바뀜. 필요한 진급 재료(아이콘·이름·보유 / 필요)를 보여주고, 모자라면 진급 버튼이 꺼지고 보유 숫자가 빨강
  - 스타일 (임시 그림, 다른 화면과 같은 패널·영문 라벨): 좌상단 OPERATOR / 전투원, 레벨은 주황색 큰 글자
- 인벤토리 (메인 화면의 DEPOT, 에픽세븐식): **무기 인벤과 재료 인벤을 따로** 둔다 (왼쪽 탭 무기 / 재료)
  - 무기: 개체 1개 = 1칸, **200칸** (임시). 칸마다 아이콘·★·레벨, 장착 중이면 E 표시. 정렬(등급순·레벨순·획득순)
  - 재료: 종류마다 1칸 + 개수, **칸 제한 없음**, 종류당 최대 **9,999개** (넘는 양은 버림)
    - 골드·보석도 재료 탭 맨 앞에 "재화"로 보임 (0개여도 표시, 최대 개수 제한 없음). 칸을 누르면 다른 재료처럼 설명이 나옴
  - 칸을 누르면 오른쪽 상세 패널: 이름·등급·스탯(무기)·장착 캐릭터 / 분류·보유 개수(재료)·설명
  - **자동 분해**: 무기 칸이 꽉 찬 상태에서 3성 무기를 얻으면 바로 분해되어 무기 강화석이 됨 (가챠 결과 카드에 "자동 분해" 표시). 4·5성은 귀하므로 칸을 넘어서라도 보관
  - **일괄 분해**: 3·4·5성 중 등급을 골라(여러 개 가능) 그 등급의 무기를 전부 분해. 장착 중인 무기는 제외. 고를 때마다 분해 대상 수와 받을 재료를 미리 보여줌
  - 분해 보상 (무기 강화석, 임시): 3성 5개 / 4성 20개 / 5성 60개
  - 수치(칸 수·최대 개수·분해 보상)는 `InventoryRules` 에셋에서 정함
  - 스타일 (임시 그림, 다른 화면과 같은 패널·영문 라벨): 좌상단 DEPOT / 창고, 칸 테두리·아래쪽 빛은 등급 색(3성 파랑·4성 보라·5성 황금빛, 가챠와 같음), 일괄 분해 창은 붉은 강조
- 심사자용 디버그 모드: 재화 무한, 모든 스테이지 개방

## 3. 전투 시스템

### 3-1. 스킬 구조
- **1스(평타) / 2스 / 3스 + 패시브**, 스킬은 쿨타임 방식
- 전투 시작 시 모든 스킬 사용 가능 (쿨타임 0). 캐릭터 컨셉상 예외는 스킬 데이터의 **시작 쿨타임**으로 처리
- 쿨타임과 버프·디버프 지속시간은 **보유자의 개인 턴** 기준으로 감소

### 3-2. 스탯
- 공격력 / 방어력 / HP / 치명확률 / 치명피해 / 속도
- 효과 적중·효과 저항 스탯은 없음 (디버프는 100% 적용)
- 직군 4종: 공격 / 지원 / 방어 / 회복

### 3-3. 행동 순서 (붕괴 스타레일식)
- 최종 속도 = 기초 속도 × (1 + 속도 %) + 고정 속도, 기초 속도 범위 90~130
- 각 유닛은 **남은 거리**를 저장 (전투 시작 시 전원 10000, 행동하면 10000으로 리셋)
- 행동수치 = 남은 거리 / 최종 속도 → 가장 작은 유닛이 행동하고, 나머지는 경과 시간 × 속도만큼 전진
- 속도가 바뀌어도 남은 거리는 유지되고 도착 시간만 다시 계산
- 행동 당기기 X%: 남은 거리 -= 10000 × X%
- 동시 도착 시 우선순위: 아군 → 직군(지원 → 공격 → 방어 → 회복) → 편성 순서. 적군끼리는 편성 순서
- **사이클(절대 턴) 카운터**: 경과 행동수치를 누적해 첫 사이클 150, 이후 100마다 +1
  - 용도는 별 미션 조건("N사이클 내 클리어")과 밸런스 테스트 기록으로 한정

### 3-4. 추가 턴과 추가 공격
- **추가 공격 = 조작할 수 없는 임시 턴**. 행동자의 턴이 완전히 끝난 뒤(정규 턴 종료 처리·턴 종료 단계까지) 추가 공격 하나마다 임시 턴 하나로 실행
- 턴 종료는 두 가지로 나눈다
  - **정규 턴 종료 처리**: 지속피해 발동, 상태효과 남은 턴 감소, 쿨타임 감소, 행동 게이지 리셋
  - **턴 종료 단계 효과**: 턴이 끝나면 받는 효과 (강탈한 버프 획득, 강탈 딜러 추격 등)

| | 추가 턴 | 추가 공격 (임시 턴: 반격, 처치 반응 등) |
|---|---|---|
| 행동 | 스킬을 골라 즉시 한 번 더 행동 | 정해진 공격이 자동 발동 |
| 행동 게이지 | 변화 없음 | 변화 없음 |
| 쿨타임·지속시간 감소 | O (턴을 한 번 더 받는 것이므로 일반 턴과 동일) | X |
| 정규 턴 종료 처리 (지속피해 등) | O | X |
| 턴 종료 단계 효과 | O | O (그 추가 공격이 끝난 직후) |
| 패시브 턴당 횟수 초기화 | O | X (추가 공격을 일으킨 정규 턴에 묶어 연쇄를 끊음) |
| 하이퍼캐리 행동 횟수 | 해당 없음 | 포함하지 않음 |

- 추가 턴도 쿨타임이 줄어들므로, 추가 턴을 주는 스킬은 쿨타임을 길게 잡아 루프를 막는다
- 추가 공격으로 적을 처치해도 처치 반응 추가 공격은 다시 발동하지 않음 (무한 연쇄 방지)
- **예외: HP 50% 돌파 반응**(A 돌파 반응 딜러)은 추가 공격으로 돌파해도 쌓임 (자기 추가 공격 포함)
  - 적 1명이 50% 초과 → 이하로 내려갈 때 1회라서, 50% 위로 회복하지 않는 한 연쇄는 적 수만큼에서 끝남
- "아군 공격 시" 반응은 **정규 행동(스킬, 추가 턴에 쓴 스킬 포함)에만** 발동하고, 추가 공격에는 발동하지 않음 (테스트하며 재검토)
  - 추가 공격이 추가 공격을 부르는 연쇄를 없애 읽기 쉽고, 반응 횟수가 아군 스킬 횟수에 비례하게 함
  - "공격 판정 시"(화상 부여 등)와 "처치 시" 반응은 추가 공격에도 발동
- 반응형 패시브는 반드시 스택·턴당 횟수 같은 제한을 가져, 연쇄가 언제나 끝나도록 한다
- 후속 행동은 현재 턴이 완전히 끝난 뒤 실행: 정규 턴 종료 → 끌어온 턴들(반격 태세, 각자 그 턴의 추가 공격 포함) → 추가 공격(임시 턴)들 → 추가 턴
  - 행동자의 턴 종료 지속피해로 노리던 적이 쓰러졌으면, 추가 공격은 살아 있는 적을 다시 고른다

### 3-5. 피해 공식
- **최종 피해 = ATK × 스킬 배율 × (1 + 피해 증가 합계) × 치명타 배율 × 방어력 배율 × (1 + 받는 피해 증가 합계) × (1 - 피해 감소율)**
  - 같은 칸(괄호) 안은 합연산, 칸끼리는 곱연산
  - 치명타 배율: 치명 발생 시 1 + 치명피해, 아니면 1
  - 피해 증가는 공격자 쪽, 받는 피해 증가·피해 감소는 대상 쪽 보정
  - **피해 감소만 효과끼리 곱연산**: 감소율 = 1 - (1 - a)(1 - b)…, **최대 75%** (많이 쌓을수록 효율 감소)
    - 예: 40% + 30% → 58%
- **방어력 배율 = K / (K + 유효 DEF)**
  - 유효 DEF = DEF × (1 - 방어력 감소) × (1 - 방어력 관통) — 관통은 이후 구현, 방어력 감소는 방어력 % 디버프로 처리
  - K = 공격자 레벨의 균형형 방어력 × (1 - 0.35) / 0.35 → 같은 레벨 적에게 피해 35% 감소
- 최종 피해는 내림, 최소 1

### 3-6. 치명타
- 치명확률·치명피해는 캐릭터마다 데이터에 설정 (장비가 생기면 장비로도 증감, 버프로도 증감 가능)
- 치명타는 **공격 행동(스킬, 추가 공격)에만** 적용. 지속피해·회복에는 적용하지 않음
- 강탈 딜러·하이퍼캐리 딜러는 기본 치명확률 80%, 치명 버퍼(+20%)와 함께 써야 확정 치명
- 치명확률 상한 100%
- 적이 치명확률 버프를 걸면 확정 치명 딜러에게는 의미가 없으므로, 적 버프는 공증·치피증·속증 위주로 설계

### 3-7. 상태효과
- 한 개체당 **버프 10칸, 디버프 10칸** (서로 분리)
- 중첩 = 개별 인스턴스. 독 3개를 걸면 3턴짜리 독 3개가 각각 1칸씩 차지
  - 인스턴스마다 남은 턴과 시전 당시 시전자 공격력(스냅샷)을 따로 가짐
- 칸이 가득 차면 **남은 턴이 가장 짧은 것을 밀어내고** 새 효과가 들어감 (남은 턴이 같으면 먼저 걸린 것부터)
- **버프**: 같은 버프(같은 에셋)는 중첩 불가 → 남은 턴만 갱신. 다른 버프는 효과가 같아도 각각 적용
  - 예외: 버프도 상태효과 데이터의 **중첩 방식**을 따름. 아군 버프는 모두 갱신이고, 적 전용 버프만 예외로 둠
    - **중첩 버프** (보스 1 공세): 걸 때마다 새 칸을 차지 (화상·독과 같음). 강탈하면 칸 수만큼 새 버프 → 강탈 딜러 게이지·3스 버프 수가 그만큼 늘어남
      - 공·방 % 버프면 칸끼리도 중첩 감소 (20% × 10칸 ≈ +89%)
    - **스택 버프** (지금 쓰는 효과 없음): 1칸에 숫자로 쌓임. 스탯 보정 = 1스택 수치 × 스택 수를 버프 하나로 계산. 강탈하면 스택째 새 버프 1개, 같은 스택 버프를 이미 가졌으면 스택을 합침
  - 예: 버퍼의 "피해 증가" 20% + 강탈 딜러의 "추격" 20% → 피해 증가 40%
  - **예외: 공격력·방어력 % 증가 버프끼리는 중첩 감소** (피해 감소와 같은 곱연산): 합계 = 1 - (1 - a)(1 - b)…
    - 예: 공뻥 30% + 광폭 30% → 51% (단순 합 60%), 방뻥 50% + 경화 50% → 75% (단순 합 100%)
    - 이유: 아군 버퍼의 버프와 적에게서 뺏은 버프(광폭·경화)가 같은 스탯에 겹치기 쉬워, 단순 합이면 스탯이 지나치게 커짐
    - 디버프(감소)와 오라·변신 보정은 중첩 감소 없이 그대로 더함
- 적이 거는 버프는 아군 버프와 **별도 에셋**으로 만든다 (광폭 = 공격력 증가, 경화 = 방어력 증가)
  - 같은 에셋이면 강탈해도 갱신으로 처리되어 강탈 딜러의 버프 가속·3스 버프 개수가 늘지 않기 때문
  - 같은 버프인지는 화면 이름이 아니라 에셋으로 판단
- **디버프**: 상태효과 데이터의 **중첩 방식**을 따름
  - 중첩(기본, 화상·독): 걸 때마다 새 인스턴스가 칸을 차지
  - 스택: 1칸에 모아 걸 때마다 스택 +1(최대 스택까지), 남은 턴은 처음 값으로 되돌림. 피해 = 1스택 피해 × 스택 수 (시험해 봤다가 되돌림, 지금 쓰는 효과 없음)
  - 갱신: 같은 효과가 이미 있으면 새로 추가하지 않고 남은 턴만 초기값으로 되돌림
- 해제 불가 버프는 만들지 않음
- **지연 버프**: 걸려 있는 동안은 효과가 없고, 지워지면 지정된 다른 버프로 바뀜
  - "지워짐" = 남은 턴 만료, 해제, 소모(강탈 딜러 3스), 보호막 깨짐, 칸이 넘쳐 밀려남. **사망과 강탈은 제외** (강탈은 효과가 그대로 옮겨가는 것)
  - 바뀐 버프는 그 턴의 종료 단계에 받음 (강탈 버프·추격과 같은 원칙). 부여자는 지연 버프를 건 유닛 그대로
  - 바뀐 버프는 일반 버프라 다시 바뀌지 않음 → 연쇄는 지연 버프 개수만큼에서 끝남
  - 바뀐 버프가 같은 버프를 이미 가진 경우는 일반 규칙대로 갱신 (예외 처리 없음)
- **보호막**: 버프 칸을 쓰는 일반 버프. 피해(지속피해 포함)를 보호막이 먼저 흡수하고, 다 깎이면 깨져 사라짐
  - **유닛당 하나**: 누가 어떤 스킬로 주든 보호막은 하나로 합쳐짐 (버프 1칸, 아이콘 1개)
  - 새 보호막을 받으면 **양은 더해지고** 남은 턴은 긴 쪽으로 맞춤. 같은 스킬을 다시 써도 더해짐 (쿨타임이 쌓이는 속도를 제한)
  - 이미 보호막이 있을 때 받는 보호막은 갱신이라 "새 버프"가 아님 → 강탈 딜러 버프 가속은 처음 받을 때만
  - 보호막에 양을 보탠 유닛은 모두 부여자로 봄 → 깨지거나 만료되면 보탠 유닛 모두의 "자신이 건 버프가 지워질 때" 패시브가 반응 (곰인형 버퍼)
  - 버프이므로 강탈 딜러 3스에 함께 소모됨
  - 하단 아군 초상화 카드: 보호막이 있으면 HP바를 감싸는 보호막 막대(보호막 양 / 최대 HP, 넘치면 꽉 참)가 보이고, 숫자는 HP 대신 보호막 양
- **디버프 면역**: 걸려 있는 동안 **새로 걸리는** 디버프를 모두 막음. 이미 걸린 디버프는 지우지 않음 (도발 탱커 3스)
- **무적 (버프)**: 걸려 있는 동안 모든 피해(지속피해 포함)가 0, 보호막도 깎이지 않음 (부활 힐러 3스, 1턴). 몬스터용 무적과 이름·아이콘이 같지만 남은 턴이 있는 버프라 강탈·소모 대상이고, 승리 조건(무적이 아닌 적 전멸)과는 무관
- **시선집중**: 상대의 단일·확산 공격이 시선집중 중인 유닛만 노림 (광역은 그대로). 버프 칸을 쓰지 않는 상태라 아이콘만 표시되고 강탈·소모·밀어내기 대상이 아님
  - 지금은 도발 탱커 패시브로만 생김 (보호막이 있는 동안). 같은 편에 여럿이면 편성 순서가 앞인 유닛
- **행동 제어**: 기절처럼 행동을 막는 효과. 행동 제어 면역(하이퍼캐리 변신 중)인 대상에게는 걸리지 않음
- **기절**: 자기 턴이 와도 행동하지 못하고 턴을 넘김. 턴 종료 처리(지속피해, 남은 턴 감소 등)는 그대로 진행되어 1턴 기절은 그 턴이 끝나며 풀림
- **지속 회복 (소생)**: 보유자의 턴 종료 시 회복. 회복량 = 부여 당시 시전자 최대 HP × n% (스냅샷)
  - 지속피해 다음에 회복 → 같은 턴 지속피해로 HP 0이 됐으면 회복되지 않음 (회복으로는 부활하지 않음)
  - 회복이므로 치명타·방어력 미적용
- **오라**: 버프 칸에 들어가지 않는 효과. 오라 주인이 살아 있는 동안(패시브 오라) 또는 오라를 생성하는 동안(공연 등 기간 오라) 같은 편 전원에게 적용
  - 버프 칸이 아니므로 강탈·소모·만료·밀어내기 대상이 아니고, 공격력 버프와의 중첩 감소도 없이 그대로 더해짐
  - **퇴장해도 유지**: 하이퍼캐리 3스로 아군이 퇴장해도 퇴장한 유닛의 오라는 계속 적용되고, 퇴장한 유닛도 오라를 받음 (주인이 쓰러지면 즉시 꺼짐)
  - **모든 오라는 전장에 이펙트**가 보여, 적용 중인지 눈으로 알 수 있음 (오라마다 전용 이펙트. 지금은 아스트라 공연만, 독 서브딜러 오라는 이후)
- 범용 버프: 소생(최대 HP 5% 지속 회복, 2턴), 가속(속도 +20%), 치명 확률 증가(+20%, 3턴) — 수치 임시
  - 가속은 적 쪽(2턴, 가호의 사도·Enemy_Healer)과 아군 쪽(3턴, 니콜, `AllyHaste`)을 별도 에셋으로 나눔 → 강탈하면 아군 가속과 따로 쌓임
- 아군 지원 버프 지속은 3턴 (공격력·방어력·치명 피해·치명 확률 증가, 가속, 곰돌이의 응원·축복): 강탈 딜러가 버프를 받을 때마다 당겨져 턴이 빨리 돌기 때문에, 2턴이면 3스 전에 먼저 만료됨 (아래 강탈 파티 템포)
- 범용 디버프: 방어력 감소(-50%, 2턴), 공격력 감소(-50%, 3턴), 둘 다 갱신 방식 — 수치 임시
  - 스킬에서는 "상태효과 부여" 블록에 이 효과를 넣어 건다
  - 적 전용 버프를 따로 둘지(강탈 시 갱신 문제)는 광폭·경화와 함께 재검토 중
- 효과 저항이 없으므로 보스 쪽 조절은 특정 디버프 면역, 디버프 해제 패턴으로 한다

### 3-8. 지속피해
| 타입 | 피해 | 사용 캐릭터 |
|---|---|---|
| 화상 | 시전자 공격력 60% | S 격발 딜러 (공격력이 높은 S가 공격력 비례) |
| 독 | 대상 최대 HP 5%, 상한 없음 (HP가 높은 적일수록 강함) | A 중첩 딜러 (공격력이 낮은 A가 최대 HP 비례) |

- 둘 다 중첩 가능, 치명타 없음
- 공격자 쪽 보정은 **부여 당시 공격력(스냅샷)만** 반영 → 공격력 증가 버프는 효과가 있고, 피해 증가 버프는 효과 없음
- 대상 쪽 보정(받는 피해 증가, 피해 감소)은 일반 공격과 똑같이 적용
- 예외: **지속피해 증가**(독 서브딜러 오라 등)는 공격자 쪽이지만 스냅샷이 아니라 **발동할 때의 값**을 적용 → 오라 주인이 쓰러지면 즉시 꺼짐
- 최종 지속피해 = 기본 피해 × (1 + 지속피해 증가) × 방어력 배율 × (1 + 받는 피해 증가) × (1 - 피해 감소)
- 발동 시점: 대상의 매 턴 종료 시
- **격발**: 대상에게 걸린 모든 지속피해가 즉시 1회씩 발동하고, 지속피해는 그대로 유지
- 독 상한 배율은 SO 설정값 (0 = 상한 없음, 지금은 0으로 테스트 중)

### 3-9. 전투 진행
- **사망 판정**: HP가 0이 되는 피해를 받아도 그 스킬의 모든 계산·효과(강탈, 상태효과 부여 등)를 끝까지 받은 뒤, 공격이 끝나면 사망
  - 처치 시 발동 효과(강탈 딜러 추격)는 사망 처리 이후 발동
  - 강탈 딜러 추격처럼 자기 버프를 얻는 처치 효과는 그 턴의 종료 단계에서 적용 (같은 스킬의 버프 소모에 휘말리지 않도록)
  - 추가 공격으로 처치했다면 그 추가 공격(임시 턴)의 종료 단계에서 적용
  - HP 0인 상태로 남아 있는 것은 그 공격 안에서만. 공격이 끝나면 사망하므로 이후 추가 공격의 대상이 될 수 없음
- **웨이브 전환**: 쿨타임·버프·디버프·변신 상태 등 모두 유지, 행동 게이지만 초기화 (남은 거리 10000)
  - 웨이브 클리어 = 무적이 아닌 적 전멸. 추가 공격까지 모두 끝난 뒤 다음 웨이브로 넘어감 (남은 무적 적은 웨이브와 함께 퇴장)
  - 사이클 카운터는 웨이브가 바뀌어도 이어서 셈
- **승리**: 마지막 웨이브 적 전멸 / **패배**: 아군 전멸
- **부활** (부활 힐러): 쓰러진 아군을 다시 전장에 세움
  - HP: 효과마다 정한 최대 HP 비율 (지금은 모두 50%)
  - 버프·디버프: 쓰러질 때 모두 사라진 것으로 봄 → 빈 상태로 부활 (사라질 때 지연 버프 변환·"버프 지워짐" 반응 없음)
  - 쿨타임·패시브 스택: 쓰러질 때 값 그대로
  - 행동 게이지: 처음부터 (남은 거리 10000). 자가 부활 패시브는 그 뒤 +50% 당김
  - 처치 반응(강탈 딜러 추격 등)은 그대로 발동하고, 부활은 사망 확정 뒤에 일어남
  - 패배 판정은 부활 처리 뒤에 하므로, 아군이 동시에 전멸해도 자가 부활이 남아 있으면 패배가 아님
  - 회복 효과로는 부활하지 않음 (부활은 부활 효과만)
- 자동 전투, 배속 지원

### 3-10. 적 AI
- **현재 구현: 패턴 목록** (조건 → 스킬·대상)을 위에서부터 확인해 조건이 맞는 첫 패턴 실행. 보스 3종 기믹을 먼저 검증한 뒤 Behavior로 교체 예정
  - 조건 예: 항상, 자신의 버프 n개 이상 / 대상 예: 스킬 기본 규칙, 같은 편 중 최대 HP가 가장 높은 유닛(= 보스)
- 보스: **Unity Behavior 패키지**(Unity 6 공식)로 비헤이비어 트리 구현
  - BT는 "보스 턴에 어떤 스킬을 누구에게 쓸지" 판단만 담당, 실제 피해·상태효과 처리는 전투 시스템(C#)이 담당
  - 흐름: 전투 시스템이 보스 턴 시작을 알림 → BT 판단 → 커스텀 액션 노드가 스킬 사용 요청 → 턴 종료
- 일반 적: 랜덤한 아군 1명을 공격하는 행동만 반복 (시선집중 중인 아군이 있으면 그 아군만 공격)

### 3-12. 경계
- **경계** = 전장 전체에 펼쳐지는 효과의 한 종류. 스킬 효과 목록에 "경계" 블록으로 넣는다
- 경계 공통 규칙은 하나뿐: **전장에 경계는 한 번에 하나만 존재** (중첩되지 않음)
  - 같은 편에 경계가 펼쳐져 있는 동안 아군은 경계 스킬(경계 블록이 든 스킬)을 쓸 수 없음 → 교체가 일어나지 않음
  - 적의 경계는 아직 계획 없음. 혹시 새 경계가 들어오면 기존 경계는 끝나고(종료 처리까지 진행) 새 경계로 바뀜
- 무엇을 하는지, 언제 끝나는지는 경계마다 따로 정한다
- 경계의 효과는 펼친 유닛에게 걸리며, 버프 칸을 쓰지 않음 → 강탈·소모·만료되지 않고 공격력 버프와 중첩 감소도 없음
  - 머리 위에는 자기 버프처럼 경계 아이콘(파란 바탕·검은 그림)이 보이고, 누르면 툴팁
- 현재 경계
  | 경계 | 효과 | 종료 | 사용 |
  |---|---|---|---|
  | 고립 | 공격력 +60%, 방어력 +30%, 최대 HP +200% (늘어난 최대 HP만큼 현재 HP도 증가), 행동 제어 면역 | 펼친 유닛의 변신이 끝날 때, 또는 펼친 유닛이 쓰러질 때 (최대 HP가 줄면 넘치는 현재 HP는 최대 HP로) | 하이퍼캐리 3스 |

### 3-11. 전투 UI (스타세이비어 전투 화면 참고)
- **장면 연출 (붕괴 스타레일식, 현재 구현)**: 고정된 전장을 카메라가 돌아다니지 않고, 장면마다 필요한 유닛만 그 장면 자리에 다시 세운다. 무대가 바뀔 때는 짧게 어두워졌다 밝아짐
  - 아군 차례: 그 아군 하나만 앞에 서고(나머지 아군은 숨김) 적은 멀리 한 줄 → 아군 어깨 뒤에서 몸 전체 + 멀리 적이 보이는 구도
  - 스킬 버튼을 눌러 고르면 같은 무대에서 스킬마다 다른 각도로 부드럽게 바뀜 (차례 시작 때는 1스 구도, 마우스를 올리는 것만으로는 안 바뀜)
  - 아군 전체·아군 단일 스킬을 고르면: 아군 전원이 카메라를 보고 나란히 섬 (적은 숨김). 고를 수 있는 아군에 하늘색 조준 고리 → 3D 고리나 아래 초상화 카드를 눌러 선택
  - 자신에게 쓰는 스킬: 그 아군을 정면에서
  - 적 차례: 평소 아군 시점(아군 줄 + 멀리 적 줄) 그대로 맞는 모습을 봄
  - 화면 아래 아군 초상화 바: 일러스트 머리 + 이름(스택) + HP바·숫자, 차례인 아군 금색 테두리, 고를 수 있으면 하늘색 테두리, 쓰러짐·퇴장은 어둡게. 아군 머리 위 이름표·버프 아이콘은 숨김(카드에서 보여주므로, 적은 그대로)
    - 카드 아래에 **버프 줄(위)·디버프 줄(아래)을 나눠** 작은 아이콘을 줄마다 최대 5개 (버프 파랑·디버프 빨강 바탕, 남은 턴 숫자), 넘치면 "…"
    - 카드를 **꾹 누르면** 상세 창: 화면 가운데 캐릭터 일러스트 + 오른쪽 패널에 탭 3개 (마지막에 고른 탭 유지). 바깥을 누르면 닫힘
      - 스탯: 공격력·방어력·HP·속도·치명 확률·치명 피해·피해 증가, 기본보다 오른 만큼 초록 (+n)·내려간 만큼 빨강
      - 버프·디버프: 왼쪽 버프·오른쪽 디버프 두 칸으로 나눠, 효과마다 카드 한 장(아이콘·이름·분류·남은 턴·설명·수치·부여자)
      - 스킬: 1~3스(대상·쿨타임·남은 쿨타임·효과) + 패시브(발동 조건·횟수 제한·스택·효과) + 변신 스킬·종결기. 효과 설명은 스킬 데이터에서 자동으로 만들어 수치를 바꿔도 따로 고치지 않음
  - 구도 값(위치·바라볼 곳·화각)은 Battle 씬 카메라의 `BattleCameraDirector`에서 조정
  - 차례 장면(스킬 구도 1~3)은 행동 유닛이 화면 왼쪽에 서도록 카메라를 오른쪽 뒤에 둠 → 멀리 선 상대 줄을 가리지 않게
  - 입체감 (붕괴 스타레일 전투 화면 참고): 아군 차례에는 행동 유닛이 **화면 왼쪽에 몸 전체**로 서고, 상대 무리는 **오른쪽 앞에 비스듬한 한 줄**로 서서 화면 가운데~오른쪽에 가로로 펼쳐짐
    - 카메라는 행동 유닛의 왼쪽 뒤, 머리보다 조금 높은 곳(1.2~2.2)에서 상대 무리 쪽을 봄. 화각 50~52
    - 상대 줄은 카메라 시선과 거의 수직으로 뻗어 서로 겹치지 않고, 각자 행동 유닛을 바라봄. 행동 유닛도 상대 무리 쪽을 바라봄
    - 간격은 3명까지 3.3으로 넓게, 그보다 많으면 줄 양 끝이 9를 넘지 않게 좁힘. 4명 이상이면 늘어난 인원만큼 줄을 오른쪽으로 더 밀어 왼쪽 끝이 행동 유닛과 겹치지 않게 함
  - 오라 전장 이펙트(아스트라 공연 악보)는 카메라를 따라와 언제나 카메라 앞 7 거리에서 화면을 가로지름 (장면마다 구도가 달라도 보이도록)
    - 적 차례(아군 줄 + 멀리 적 줄)는 휜 호 배치 그대로 (줄 끝이 가운데보다 1.6 앞, 거리 7.5, 간격 2.8)
    - 임시 바닥: 어두운 남색 격자 (`Art/Battle/Floor`), 그림자, 어두운 배경 + 안개로 바닥 끝을 감춤
- 전투 로그: 화면에서는 숨김 (콘솔에는 그대로 남음)
- 좌상단: 웨이브 (1/2), 사이클 카운터
- 상단 중앙: 보스 초상화·이름·HP바, 그 아래 보스 버프·디버프 아이콘 (현재 구현)
  - 적 데이터에 "보스" 표시가 된 적이 지금 웨이브 전장에 있을 때만 보임 (축적의 수호자, 군단 지휘관, 기본 스테이지 보스)
  - 이름 + 오른쪽 위 HP 숫자(현재 / 최대), 금빛 테두리의 큰 HP바(10% 눈금, 깎인 만큼 밝은 잔상이 천천히 따라 줄어듦). 보호막이 있으면 HP바를 감싸는 막대 + "보호막 n" (아군 카드와 같은 규칙)
  - 보스는 머리 위 상태효과 줄을 끄고 이 바에서만 보여줌
  - HP바 아래에 버프 줄(왼쪽)·디버프 줄(오른쪽), 줄마다 5칸 + "…". 지휘·자폭 준비 같은 표시용 아이콘도 포함
  - 바를 누르면 상세 창(스탯·걸린 효과 전부)
- 적 머리 위: 작은 HP바, 타겟 표시
- **적 꾹 누르기**: 전장의 캡슐(적·아군 모두)을 꾹 누르면 아군 카드와 같은 상세 창(스탯 / 버프·디버프 / 스킬). 짧게 눌렀다 떼면 지금처럼 대상 선택
- **보스 스킬 이름 (현재 구현)**: 보스가 스킬(패턴)을 쓰면 보스 HP바 아래에 "보스 이름 + 스킬 이름" 띠가 잠깐 뜨고, 이름을 읽을 틈(약 0.5초) 뒤에 공격 모션
  - 어두운 띠 + 붉은 위아래 선. 추가 공격·패시브는 띄우지 않음. 일반 적까지 띄울지는 BattleFx의 "보스만" 체크로 바꿈
- 좌측: 사용한 스킬 이름 알림 (아군은 아직)
- 좌하단: 현재 행동 캐릭터 초상화·이름·HP, 행동 순서 바 (초상화 + 행동 게이지 %)
  - 현재 구현 (붕괴 스타레일식): 좌상단 세로 목록. 맨 위 = 지금 행동 중(1.3배 크게), 아래로 다음 행동 순서 8개
    - 칸마다 원형 초상화(일러스트 머리 부분, 일러스트가 없으면 편 색 바탕 + 이름 첫 글자) + 오른쪽에 이름(굵게)·행동 게이지 %
  - 속도가 빠른 유닛은 여러 번 나오며 게이지는 처음 나온 칸에만 표시. 현재 속도가 유지된다고 가정한 예측 (버프 만료·행동 당기기는 실제 진행 때 반영)
  - 원 테두리 색: 아군 하늘색, 적 빨강, 지금 행동 중 금색. 퇴장한 아군·쓰러진 유닛은 목록에서 빠짐
  - 움직이는 순서 바: 차례가 지나면 칸들이 한 칸씩 위로 미끄러지고 행동을 마친 칸은 왼쪽으로 빠지며 사라짐. 새 칸은 아래에서 떠오름
    - 행동 당기기(강탈 딜러 버프 가속 등)로 순서가 앞당겨지면 그 칸이 위로 휙 올라가며 이름 옆에 초록 "+30%"가 잠깐 뜸
- 우하단: 스킬 버튼 3개 (붕괴 스타레일식 원형, 1스 작게 → 3스 가장 크게)
  - 원 안에 스킬 이름, 원 아래 1스·2스·3스. 쿨타임 중이면 원을 어둡게 덮고 남은 턴 숫자만 크게
  - 고른 스킬은 금색 테두리 + 뒤 빛 + 살짝 커짐. 버튼 위 이름판에 "n스 스킬 이름" + 다음 할 일(강조된 대상 누르기 / 한 번 더 눌러 사용)
- 임시 연출 (모션 전): 맞은 유닛에 타격 이펙트 + 피해 숫자, 회복받은 유닛에 회복 이펙트 + 회복량, 버프받은 유닛에 버프 이펙트 + 버프 이름
  - 피해 숫자: 일반 흰색, 치명 노란 큰 숫자 + "!", 무적 회색 "무적", 보호막 흡수량은 아랫줄
  - 지속피해 숫자: 종류마다 색이 다름 (화상 빨강, 독 초록, 상태효과 데이터의 "피해 숫자 색"). 한 번에 터진 지속피해(턴 종료 발동, 격발)는 하나씩 박자를 나누지 않고 아주 짧은 간격으로 넓게 흩뿌려 한꺼번에 파파팍 뜸
    - 격발 스킬 자체의 타격 숫자는 일반 숫자로 먼저 뜨고, 그다음 지속피해 묶음
  - 숫자는 계산된 피해 그대로 표시 (남은 HP보다 커도 원래 피해. HP는 0 밑으로 내려가지 않음, 로그도 같음)
  - 한 행동에서 일어난 일을 발동 순서대로 간격을 두고 보여주고, 다 보여준 뒤 다음 턴으로 넘어감
  - 한 스킬이 같은 유닛에게 버프 여러 개를 걸면 한 번에 묶어 이름을 여러 줄로 보여줌 (니콜 3스 치명 확률·가속, 수나 3스 4개)
- **타격감 (임시, 모델링 없이 코드·UI로)**
  - **모든 행동에 모션**: 스킬, 추가 공격(격발 딜러 추격·돌파 딜러 다타·반격 등), 따로 보이는 패시브(아스트라 쉬는 턴 회복, 강탈 딜러 추격 획득, 자가 부활, 등장 소환)
    - 공격 돌진: 상대를 노리는 행동이면 공격자 캡슐이 대상 쪽으로 튀어 나갔다 돌아옴 (아군·적 모두). 타격은 돌진이 닿는 순간에 나옴
    - 시전(버프·회복): 상대를 노리지 않는 행동이면 제자리에서 떠오르며 금빛으로 빛났다 내려옴. 버프·회복은 가장 높이 떴을 때 나옴
    - 공격 판정에 묻는 효과(화상 부여, 이자 스택)와 내부 처리(버프 가속 게이지, 곰인형 쿨타임 감소)는 따로 모션 없음
    - 행동하는 유닛이 화면에 없으면(아군 차례 장면은 그 아군만 보임) 그 유닛이 보이는 장면으로 바꾼 뒤 모션: 아군 공격 = 그 아군 어깨 뒤, 아군 여럿에게 버프 = 아군 줄 정면, 자기 강화 = 그 아군 정면
  - 피격 반응: 맞은 캡슐이 하얗게 번쩍 + 공격 반대쪽으로 밀렸다 흔들리며 돌아옴 (치명은 더 크게, 지속피해는 작게)
  - 히트스톱: 맞는 순간 아주 잠깐 멈춤 (일반 0.04초, 치명 0.08초, 처치 0.1초)
  - 화면 흔들림: 일반 약하게, 치명·처치 세게, 3스는 더 세게. 광역기로 여럿 맞아도 한 번
  - 처치: 멈춘 뒤 0.35초 슬로모션 + 쓰러진 캡슐이 포물선으로 날아가며 넘어짐
  - 피해 숫자: 작게 나타나 크게 튀었다가 원래 크기로 (치명은 더 크게 + 살짝 기울어짐)
  - **보호막 깨짐**: 보호막이 다 깎이는 순간 하늘색 파편이 튀고 고리가 퍼지며 "보호막 파괴" 글자
  - **HP바 흔들림**: 최대 HP의 5% 이상 맞으면 그 아군 카드·보스 HP바가 0.3초 흔들림 (많이 맞을수록·치명일수록 세게)
  - **연출 다단 히트** (스킬 데이터 "연출 타수"): 같은 피해를 그 수만큼 나눠 숫자·HP 감소·피격 반응을 0.1초 간격으로 연달아 보여줌 (피해 합계는 그대로). 중간 타는 약하게, 마지막 타만 원래 세기·처치 연출. 지금은 선브링어 변신 3스(섬멸)만 4타
  - **스킬 전용 연출 (임시)**: 스킬 데이터에 전용 연출 프리팹을 넣으면 기본 돌진 대신 그 연출이 나오고, 연출이 대상에 닿는 순간 그 대상의 피해 숫자·타격이 뜸
    - 선브링어 변신 3스(섬멸) = 메테오 (돌진 없음)
      1. 시전자가 떠오르며 빛남 → 잔챙이 메테오 7개가 대상들에게 돌아가며 떨어져 터짐. 맞은 대상에게 피해의 일부(대상마다 합쳐 30%)를 약한 타격으로 보여줌
      2. 거대 메테오(지름 12 = 적 키의 6배, 용암 균열이 빛나는 울퉁불퉁한 바위 + 불길·불씨, 굴러가며 낙하)가 떨어지기 시작하면 **적 시점으로 컷**: 적들 옆 낮은 곳에서 하늘을 올려다보며 메테오가 내려오는 모습
      3. 땅에 닿기 직전 **선브링어 시점으로 컷** → 거대 폭발(섬광·불덩이·불꽃·충격파·파편)과 함께 대상 전원에게 남은 피해 + 강한 흔들림
      - 개수·크기·낙하 시간·컷 시점·카메라 위치는 `FxMeteorShower` 프리팹 Inspector에서 조절
    - 격발 딜러 2스 = 거미줄 폭발 (돌진 없음)
      1. 적 무리 가운데에 카메라를 마주 보는 분홍빛 거미줄이 펼쳐짐: 중심에서 바퀴살이 뻗고 안쪽부터 고리 줄이 감김
      2. 점점 빨라지는 맥동과 함께 거미줄이 밝아짐
      3. 거미줄이 번쩍이며 실이 엇갈리는 매듭마다 불꽃이 터짐 → 대상 전원 피해 + 흔들림
      4. 거미줄이 매듭 사이 조각으로 끊어져 바깥으로 튀어 나가며 돌고, 가늘어지며 사라짐
      - 크기·바퀴살·고리 수·조각이 튀는 거리·시간은 `FxWebBurst` 프리팹 Inspector에서 조절
    - 격발 딜러 3스 = 실 새장 (돌진 없음)
      1. 대상 가까이로 컷 → 대상 머리 위 높은 한 점에서 보랏빛 실 14가닥이 하나씩 빠르게 내려와 둘레 바닥에 꽂힘 (새장)
      2. 실이 꽂힌 자리가 대상 쪽으로 좁혀지며 새장이 오므라들고, 팽팽해진 실이 떨리며 맥동이 빨라짐 → 잠깐 어두워짐
      3. 하늘에서 대상에게 번개가 내리치고 실들도 번개처럼 지직거림 + 보랏빛 폭발 → 대상 피해 + 강한 흔들림 → 원래 시점
      - 격발로 터지는 지속피해 숫자는 그 뒤에 이어서 뜸
      - 실 수·새장 크기·조이기·번개·카메라는 `FxBindingBurst` 프리팹 Inspector에서 조절
    - 하이퍼캐리 2스 = 황금 검기 (적 무리 쪽으로 돌진)
      - 캐리 어깨 뒤·옆에서 캐리와 적 무리를 함께 보는 시점으로 컷
      - 캐리 바로 앞에서 초승달 검흔이 한쪽 옆에서 반대쪽 옆으로 가로로 그어지고(조금 비스듬히), 그 초승달이 캐리를 중심으로 커지며 앞으로 날아감
      - 검기가 적에게 닿는 순간 그 적에게 피해 + 금빛 불꽃 + 흔들림, 적 무리를 지나며 굵어지고 사라짐 → 원래 시점
      - 검흔 3겹: 바깥 날 흰빛 금색, 가운데 금색(양 끝 보랏빛), 안쪽 검보랏빛 (변신 날개의 금·검보라 두 색)
      - 감싸는 각도·기울기·날아가는 거리·속도·겹마다 색, 카메라 위치는 `FxGoldenSlash` 프리팹 Inspector에서 조절
    - 하이퍼캐리 변신 2스(반격 태세)의 반격 = 땅 가르기 (반격 태세를 쓰는 순간은 따로 연출 없음)
      - 위에서 내려다보는 시점으로 컷 → 캐리가 적 무리 쪽으로 튀어 나가 내리치면, 앞에서 적 무리 너머까지 용암빛 균열이 땅을 타고 뻗어 감
      - 균열이 지나간 띠의 땅이 크고 작은 바위 조각으로 쪼개져 솟아오르며 제각각 기울고(균열 가까이일수록 크게), 일부는 파편으로 튀어 오름. 조각 사이로 갈래 용암 틈이 퍼짐
      - 균열이 적 발밑에 닿는 순간 그 적 아래가 터지며 피해 + 발밑 잔균열·바위 조각 + 흔들림
      - 용암빛이 잠시 남았다가 식고 바위 조각이 다시 가라앉은 뒤 원래 시점
      - 반격 추가 공격 블록의 "전용 연출" 칸에 `FxGroundSplit` 프리팹을 넣어 씀. 균열·바위 조각·파편·카메라는 그 프리팹 Inspector에서 조절
    - 레퍼런스의 "자세 잡고 끌어내리는" 모션은 모델이 생기면 추가
    - 하이퍼캐리 종결기 = 영역 붕괴 (변신 때 펼친 영역을 터뜨리며 닫는 느낌, 돌진 없음)
      1. 캐리를 낮은 곳에서 올려다보는 시점으로 컷 → 전장을 둘러싼 붉은 격자 영역 벽이 드러남
      2. 기 모으기 (약 2.6초): 영역 벽에서 붉은 기운이 캐리에게 빨려 들어오고(점점 굵어짐), 심장 박동처럼 점점 빨라지는 맥동마다 고리가 캐리 쪽으로 오그라들며 빛 덩어리가 부풀고 벽이 번쩍·화면이 떨림. 카메라는 천천히 다가가며 화각이 좁아짐
         - 터지기 직전 0.3초 숨 죽이기: 빨아들임이 멈추고 빛 덩어리가 오그라들며 벽이 어두워짐
      3. 영역 벽이 붉은 테두리의 검은 큐브 파편으로 부서져 흩어지고, 캐리 자리에서 흰빛·붉은빛 폭발 → 적 전원 피해 + 강한 흔들림
      4. 파편이 흩어지는 모습을 잠시 보여준 뒤 원래 시점으로 → 변신 해제·아군 복귀
      - 영역 크기·시간·카메라 위치는 `FxBoundaryCollapse` 프리팹 Inspector에서 조절
      - 깨지는 순간 헤일로·날개(변신 모습)도 사라짐
    - 하이퍼캐리 변신기(3스) = 황금 구체 (돌진 없음, 종결기와 짝: 영역 열기 ↔ 닫기)
      1. 캐리를 정면에서 보는 시점으로 컷 → 캐리를 감싸는 황금 구체가 부풀어 생기고, 금빛 돌 조각이 구체 둘레를 돎
      2. 힘 모으기 (약 2.2초): 빛이 구체로 빨려 들고, 구체 표면 소용돌이가 점점 빨리 흐르며, 빨라지는 맥동마다 구체가 번쩍·화면 떨림. 카메라가 천천히 다가감
      3. 잠깐 숨 죽인 뒤 구체가 금빛 파편으로 깨지며 섬광 → 헤일로·날개가 나타나고, 붉은 영역 벽이 캐리에게서 퍼져 나가며 사라짐 (고립 경계 전개)
      4. 변신한 모습을 잠시 보여준 뒤 원래 시점으로
      - 시간·크기·카메라는 `FxTransformCocoon` 프리팹 Inspector에서 조절
    - **변신 모습** (임시): 변신 중에는 캐리 뒤에 황금빛 헤일로 + 날개 + 떠다니는 금빛 알갱이
      - 헤일로: 밝은 해 + 바깥으로 휘어 나가는 가시 왕관(안쪽) + 가늘게 일렁이는 불꽃 갈래(바깥), 두 겹이 서로 반대로 천천히 돎
      - 날개: 두꺼운 날개뼈 + 넓적한 칼날 깃 7개가 이어진 일체형 (테두리가 뼈부터 깃 끝까지 한 줄로 이어짐, 깃 사이는 옅은 이음선) (왼쪽 금빛, 오른쪽 검보랏빛에 금빛 테두리), 뒤로 젖혀 천천히 펄럭임
      - 변신 데이터의 "변신 모습" 프리팹(`FxSunAppearance`)으로 정함. 나타나는 순간은 변신기 구체가 깨질 때, 사라지는 순간은 종결기 영역이 깨질 때
  - 3스 컷인: 아군이 3스를 쓰면 기울어진 띠 위로 일러스트·이름·스킬 이름이 미끄러져 지나간 뒤 돌진
  - HP바·HP 숫자(아군 카드, 보스 바, 적 머리 위)는 피해 숫자가 뜨는 순간 함께 줄어듦 (모션 → 피해 숫자 + HP 감소). 회복도 회복 숫자와 함께 늘어남
  - 쓰러짐 표시(회색 캡슐, 흐린 카드, 보스 HP바 사라짐)는 쓰러뜨린 공격(행동)의 연출이 끝난 뒤에 바뀜: 공격 모션 → 피해 → 쓰러짐 표시 → 추가 공격
  - 우상단 **이번 턴 피해 합계**: 행동 + 턴 종료 지속피해 + 추가 공격으로 들어간 피해를 맞을 때마다 더해 카운트업, 큰 타격에 튐. 아군이 준 피해는 금색, 받은 피해는 빨강. 잠시 뒤 사라짐
- 우상단: 자동 전투, 배속, 일시정지
  - 일시정지 (현재 구현): 맨 우상단 버튼 → 전투가 그 자리에서 멈추고 메뉴 **계속하기 / 메인 화면으로**. 메인 화면으로 나가면 클리어 기록 없이 로비로 돌아감 (이번 턴 피해 합계는 버튼 아래로 내림)
- 전투 종료 (임시): 화면을 어둡게 덮고 "전투 종료" + 승리/패배 + **로비** 버튼 → 로비로 돌아감 (보상·별 미션 결과는 이후)
- 상태효과 아이콘은 같은 타입끼리 묶어서 개수 표시 (예: 독 ×3)
- 스택 방식 효과의 아이콘은 남은 턴 대신 스택 수 표시 (예: ×12)
- 상태효과 아이콘을 누르면 짧은 툴팁: 이름·분류·남은 턴, 설명, 효과 수치, 부여자
  - 수치는 상태효과 데이터에서 자동으로 만들어, 수치를 바꿔도 설명을 따로 고치지 않는다
- 적 전용 버프는 아군 버프와 아이콘 모양을 다르게 (광폭 = 대검, 경화 = 큰 방패)
- 하이퍼캐리 변신 중: 퇴장한 아군은 행동 순서 바에서 회색 처리, 캐리 위에 남은 행동 횟수 표시

### 4-3. 핵심 캐릭터 스킬

#### S 지속피해 격발 딜러
- 패시브: 공격 판정이 들어갈 때 대상에게 화상 1개 부여 (공격 판정과 함께 묻어 들어감)
- 패시브 2 (지속피해 파티 TTK 단축용, 붕괴 스타레일 카프카 참고)
  - 자기 턴에 행동할 때마다 스택 1개 획득 (최대 2개). 스킬 사용이 끝난 뒤 획득하며, 추가 턴의 행동도 포함
  - 다른 아군이 스킬로 적을 공격하면 스택 1개를 소모해 그 대상에게 추가 공격 → 대상의 지속피해 격발 (다른 아군의 추가 공격에는 반응하지 않음)
  - 추가 공격도 공격 판정이므로 패시브 화상이 먼저 붙고, 그 화상까지 격발됨
  - 아군 광역 공격 시 1회만 발동, 대상 선택 우선순위: 보스 → 현재 HP가 가장 높은 적 → 편성 순서
  - 아군 **확산** 공격에는 **메인 대상**을 노림 (확산은 사실상 1인 공격이고 양옆은 여파). 메인 대상의 HP가 0이 됐으면 위 우선순위로 선택
  - 트리거가 된 공격으로 대상이 사망했으면 같은 우선순위 규칙(보스 → 현재 HP 최고 → 편성 순서)으로 살아 있는 적을 골라 발동
  - 확인 필요: 추가 공격 배율 (임시 50%)
- 1스: 공격력 100% 단일
- 2스: 공격력 n% 광역 + 화상 1개 (패시브 포함 대상당 2개)
- 3스: 공격력 n% 단일 + 대상의 모든 지속피해 격발
  - 처리 순서: 모션 → 공격 판정(피해 + 패시브 화상 부여) → 격발. 이번 공격으로 붙은 화상도 격발에 포함

#### A 지속피해 중첩 서브딜러 (독)
- 패시브 (파티 오라): 자신이 살아 있는 동안 아군 전원(자신 포함)의 지속피해 +30%
- 1스: 공격력 100% 단일 + 독 1개
- 2스 (확산): 메인 대상 공격력 n%(150%) + 편성 순서상 양옆의 적 공격력 n%(75%), 세 대상 모두 독 1개
  - 확산은 메인 대상 배율과 양옆 배율을 피해 블록에서 따로 정한다 (양옆이 메인의 몇 %인지가 아니라 각자 공격력 대비 배율)
  - 양옆은 살아 있는 적 기준 (가운데가 쓰러졌으면 그 너머의 적이 옆)
  - 양옆을 메인의 절반으로 두면 확산 총 배율이 메인의 2배(메인 1 + 양옆 0.5 × 2)라 광역기보다 약하게 유지
- 3스: 적 전체 공격력 10% + 독 3개 (약한 피해를 넣어 공격 행동으로 취급 → 격발 딜러 연쇄 격발과 연계)
- 디버프 칸 10개를 독·화상이 나눠 쓰므로, 독을 까는 타이밍과 격발 타이밍이 운영 포인트

#### S 버프 강탈 딜러
- **컨셉**: 적 버프를 뺏어 모으고(가속) → 3스로 한 번에 소모해 터뜨림 → 다시 모음. 추가 턴은 없고, 템포는 "새 버프 획득"으로 만든다
- 패시브 1 (버프 가속): **새 버프를 얻을 때마다 버프 1개당 행동 게이지 30% 당기기**
  - 강탈한 버프, 아군이 걸어준 버프, 추격 모두 포함
  - 이미 가진 버프가 **갱신**된 것은 새로 얻은 것이 아니므로 제외 (같은 버프를 반복해 걸어주는 무한 가속 방지)
  - 게이지는 100%를 넘어도 "바로 다음 행동"이 최대 (예: 버프 4개 강탈 → 120% → 바로 다음 차례)
  - 자기 턴 중에 얻은 당기기는 턴 종료(게이지 리셋) 이후에 적용
- 패시브 2 (추격): 적 처치 시 자신에게 **1턴짜리** 피해 증가 버프 "추격"(n%), 턴당 1회
  - 처치가 일어난 **턴의 종료 단계**에서 획득 → 새로 얻었으면 패시브 1로 행동 게이지 +30%
  - 턴 종료 단계는 남은 턴 감소 이후라, 1턴이어도 다음 자기 턴 행동에는 적용되고 그 턴이 끝나면 사라짐
  - 1턴인 이유: 연속 턴에 처치해도 기존 추격이 먼저 사라지고 새로 얻으므로, 처치한 턴마다 항상 +30%가 붙음 (3턴이면 갱신이 되어 당기기가 빠짐)
- 1스: 공격력 100% 단일
- 쿨타임은 짧게 (테스트 값: 2스 2, 3스 3, 3스 시작 쿨타임 1). 템포는 쿨타임이 아니라 버프 획득으로 만든다
  - 3스 쿨타임은 늘리지 않음 (현자타임이 길어짐). 시작 쿨타임 1은 첫 턴에 버프가 거의 없는 3스를 막기 위함
- **강탈 파티 템포** (세베리안 + 수나 + 니콜 + 프리스트, 행동 순서 시뮬레이션 60턴 기준)
  - 문제: 지원 셋의 3스 주기가 강탈 3스 주기의 약 2배라 3스 때 버프가 많을 때·적을 때가 번갈아 나옴 (평균 4.7개, 2~8개)
  - 속도는 거의 영향 없음: 새 버프마다 게이지 30% 당기기가 속도 차이를 덮음
  - 조정: 지원 버프 3턴 + 수나 3스 쿨타임 5 → 3 + 강탈 3스 시작 쿨타임 1 → 평균 6.8개(4~9개), 3스 횟수는 그대로
  - 프리스트 2스 공격력 증가는 수나와 같은 에셋이라 함께 걸리면 갱신(버프 수 +0)
- 2스: 공격력 n% 단일 → 대상 버프 전부 강탈 (추가 턴 없음)
  - 처리 순서: 모션 → 타격 → 강탈(대상에게서 즉시 제거) → 턴 종료 → **턴 종료 단계에서 버프 획득** + 행동 게이지
    - 제거는 즉시라, 이후의 추가 공격과 적의 다음 행동은 버프가 빠진 상태를 봄
    - 획득은 턴 종료 단계라 강탈한 턴의 남은 턴 감소를 건너뜀 → 1턴짜리 버프도 다음 자기 턴까지 유지
    - 턴 종료 단계에서는 강탈한 버프 → 추격 순서로 획득
    - 턴 종료 처리 중 강탈 딜러가 쓰러지면 들고 있던 버프는 사라짐
  - 2스로 대상이 죽어도 강탈은 적용됨 (사망 판정 규칙)
  - 강탈한 버프는 남은 턴을 그대로 계승하고, 칸이 넘치면 밀어내기 규칙 적용 (자기 버프가 밀려날 수 있음)
  - 강탈한 버프가 이미 가진 버프와 같으면 남은 턴이 긴 쪽으로 갱신해 하나만 남김 (같은 버프 중첩 불가, 패시브 1 미발동)
- 3스: 자신에게 걸린 버프 개수에 비례한 n% 단일 → **버프 전부 소모** → **대상 버프 전부 강탈** (테스트 값: 150% + 버프 1개당 80%)
  - 예: 곰돌이 4개 + 치명 버퍼 2개 + 강탈 2개 = 버프 8개 → 150% + 640% = 790%
  - 처리 순서: 모션 → 피해(버프 개수·버프 효과 모두 반영) → 버프 전부 소모 (강탈한 것, 추격, 아군이 걸어준 것 전부) → 대상 버프 강탈 (2스와 같음: 대상에게서 즉시 제거, 턴 종료 단계에 획득)
  - 3스에도 강탈을 넣은 이유: 2스(쿨 2)와 3스(쿨 3)가 6턴마다 같은 턴에 준비돼, 3스를 쓰면 강탈이 밀려 축적 해방을 허용했음 (플레이 테스트). 쿨타임을 줄이면 사실상 노쿨이라 대신 3스에 강탈을 붙임
  - 결과: 3턴 중 2턴(2스·3스)이 강탈 턴. 3스로 비운 직후 뺏은 버프가 새 버프로 들어와 게이지가 당겨져 다음 순환이 빨라짐
  - 3스로 적을 처치하면: 버프 소모 이후, 턴의 종료 단계에서 추격 획득 + 행동 게이지 30%
  - 매번 버프를 비우므로 다음에 얻는 버프가 모두 "새 버프" → 패시브 1이 다시 발동하는 순환 구조
  - 버프 1개당 배율은 소모를 전제로 높게 잡음 (n%)
- 치명 버퍼의 치명확률 +20%도 3스와 함께 소모되므로, 확정 치명은 "버퍼 → 강탈 → 3스" 한 번에 집중되는 구조

#### S 곰인형 버퍼 (이름 미정, 테스트명 BearBuffer)
- **컨셉**: 지연 버프로 "소모해도 다시 차는" 버프를 공급. 강탈 딜러의 모으기 → 소모 순환을 받쳐 줌
  - 행동 게이지 지원 캐릭터를 대체 (강탈 딜러는 새 버프 획득으로 게이지를 당기므로 버프 공급이 곧 가속)
- 패시브 (곰돌이의 정성, 임시명): 자신이 건 버프가 누구에게서든 지워지면 자신의 2스·3스 쿨타임 1 감소
  - **자기 턴 사이에 1회**: 여러 버프가 동시에 지워지거나 아군 여럿의 턴에서 만료돼도 다음 자기 턴까지 1번만
  - 지연 버프가 지워질 때, 그 결과로 받은 버프가 다시 지워질 때 각각 발동 기회가 생김
  - 아군 전체에 버프가 깔려 있어 사실상 자기 턴마다 발동 → 쿨타임이 턴당 2씩 줄어듦 (쿨타임 3이면 3스가 거의 2턴마다). 다른 파티에서 너무 자주 버프를 깔면 재조정
- 1스: 공격력 100% 단일
- 2스: 단일 아군 보호막 (시전자 최대 HP의 n%, 임시 25%, 2턴). 지연 효과 없음
- 3스: 아군 전체에 버프 4개 (쿨타임 임시 3턴, 강탈 파티 템포에 맞춰 5에서 줄임)
  - 공격력 증가, 치명 피해 증가 (즉시 효과)
  - 곰돌이의 응원 (지연) → 지워지면 공격력 증가
  - 곰돌이의 축복 (지연) → 지워지면 치명 피해 증가
  - 치명 확률이 아니라 치명 피해: 강탈 파티의 치명 버퍼(치확 +20%)와 역할이 겹치지 않고, 확정 치명 딜러에게 버려지는 수치가 없음
- 강탈 딜러와의 흐름: 3스로 새 버프 4개(게이지 +120%, 3스 배율 +4개분) → 강탈 딜러 3스로 전부 소모 → 턴 종료 단계에 공뻥·치피로 다시 받음(게이지 +60%)
- 수치 전부 임시 (버프 수치, 지속 턴, 쿨타임, 강탈 딜러 3스 버프당 배율과 함께 조정)

#### S 공연 오라 버퍼 (아스트라, 테스트명 Astra)
- **컨셉**: 3스로 "공연"을 시작하면 3턴 동안 직접 행동하지 않는 대신 아군 전체에 강한 오라를 걸고, 쉬는 턴마다 아군을 회복
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 (앙상블, 임시명): **자기 턴에 공격하지 않으면** 턴 종료 시 아군 전체(전장에 있는 유닛) 회복, 회복량 = 시전자 최대 HP × n%(15%)
  - 공격하지 않은 턴 = 공격이 아닌 스킬(2스·3스)을 쓴 턴, 공연·기절로 스킵된 턴. 추가 턴도 각각 따로 판정
  - 지속피해·지속 회복 다음에 회복 (같은 턴 지속피해로 HP 0이 된 아군은 회복되지 않음, 회복으로는 부활하지 않음)
- 1스: 공격력 100% 단일
- 2스: 아군 전체(자신 포함)의 1~3스 쿨타임 1턴 감소 (쿨타임 n(3))
  - 쿨타임은 효과가 끝난 뒤 걸리므로 방금 쓴 2스는 감소 없이 온전히 걸림
- 3스 **공연** (쿨타임 n(6)): 공연 오라를 생성 → 다음 자기 턴부터 3턴 동안 **행동이 강제로 스킵**되고, 그동안 오라 유지
  - 공연 오라: 아군 전체 치명확률 +20%, 피해 증가 +30% (가하는 피해)
  - 스킵된 턴도 "공격하지 않은 턴"이라 패시브 회복이 발동 → 공연 3턴 동안 회복 3번
  - 3번째 스킵 턴이 끝나면 공연 종료(오라 해제). 아스트라가 쓰러지면 즉시 종료
  - 스킵된 턴도 정규 턴이라 상태효과 남은 턴·쿨타임은 그대로 줄어듦
  - 공연 중 전장 이펙트: 금빛·보랏빛 악보 두 줄이 물결치며 전장을 가로질러 흐르고, 음표·높은음자리표·샵이 떠다님
  - 치명확률 +20%는 치명 버퍼와 같은 수치라, 강탈·하이퍼캐리 딜러(기본 80%)는 둘 중 하나만 있어도 확정 치명

#### S 도발 탱커 (이름 미정, 테스트명 TauntTank)
- **컨셉**: 보호막이 있는 동안 적의 단일 공격을 혼자 받아 내고, 3스로 아군 전체에 보호막과 디버프 면역을 깔아 줌
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 (시선집중): 자신에게 보호막이 있는 동안 시선집중 (3-7). 보호막이 깨지면 바로 꺼지고, 다시 보호막을 받으면 바로 켜짐
  - 곰인형 버퍼 2스 등 다른 아군이 준 보호막으로도 켜짐
  - 어그로 유지는 보호막 양으로 조절 (보호막이 쌓이므로 2스·3스를 이어 쓰면 두꺼워짐)
- 1스: 공격력 100% 단일
- 2스 (방어 태세): 자신에게 보호막(최대 HP n%(40%)) + 철벽(방어력 +50%, 3턴) (쿨타임 n(3))
  - 철벽은 탱커 전용 방어력 증가 버프(별도 에셋)라 다른 방어력 증가와 따로 걸림 (공·방 % 중첩 감소 적용)
- 3스 (수호의 맹세): 아군 전체에 보호막(시전자 최대 HP n%(30%)) + 면역(디버프 면역, 3턴) (쿨타임 n(5))
  - 쿨타임을 지속보다 길게 둬 면역에 빈틈이 생기게 함 (보스 1 축적 해방 기절을 언제나 막지는 못하도록)
  - 강탈 딜러에게는 새 버프 2개(보호막이 없었을 때) → 게이지 +60%, 3스 버프 수 +2

#### S 부활 힐러 (이름 미정, 테스트명 ReviveHealer)
- **컨셉**: 때리면서 파티 전체를 조금씩 회복하고, 쓰러진 아군을 일으켜 세움. 자신도 한 번은 다시 일어남
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 (되살아나는 빛, 임시명): 자신이 쓰러지면 최대 HP 50%로 부활 + 행동 게이지 50% 당기기. **전투당 1회**
- 1스: 공격력 100% 단일 + 아군 전체 회복 (시전자 최대 HP 10%)
  - 쿨타임 없는 1스라 비율을 낮게 둠. 아스트라(쉬는 턴에 회복)와 달리 "때리면서 회복"
- 2스 (치유의 손길): 단일 아군 회복(시전자 최대 HP n%(25%)) + 보호막(n%(20%)) + 디버프 전부 제거 (쿨타임 n(3))
- 3스 (기적): 단일 아군 (쓰러진 아군 포함) (쿨타임 n(6))
  - 쓰러진 아군: 최대 HP 50%로 부활 + 무적 1턴
  - 살아 있는 아군: 디버프 전부 제거 + 무적 1턴
  - 쓰러진 아군은 고르는 장면에서 자기 자리에 흐리게 서고, 그 자리나 하단 초상화 카드를 눌러 고름
  - 무적은 대상의 다음 자기 턴이 끝날 때까지라 축적 해방 같은 강공을 확실히 막음 → 쿨타임을 길게 둠
  - 자기 자신에게 쓰면 그 턴이 끝날 때 바로 1턴이 줄어 무적이 사라짐 (자기 턴에 받은 버프의 일반 규칙)
- 디버프 제거 블록은 "전부 / 가장 최근 1개"를 Inspector에서 고름

#### A HP 50% 돌파 반응 광역 딜러 (테스트명 GeniusAoE, 붕괴 스타레일 헤르타 참고)
- **컨셉**: 아군이 적을 50% 아래로 깎을 때마다 광역 추가 공격의 타수가 쌓임. 적이 많을수록, 아군이 고르게 깎을수록 강함
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 (돌파 반응)
  1. 아군의 공격(스킬·추가 공격, 지속피해 제외)으로 적 HP가 50% 초과에서 **50% 이하로 내려가면** 1회 쌓임
     - 같은 적은 50% 위로 회복했다가 다시 내려가야 또 쌓임 (축적의 수호자처럼 지속 회복을 받는 보스에게 여러 번 발동)
  2. 쌓인 횟수 = **광역 추가 공격의 타수**. 한 행동에서 3명이 동시에 내려가면 추가 공격 1번 × 3타 (1타 = 적 전체 공격력 n%(50%))
  3. 추가 공격 도중 다른 적이 50% 아래로 내려가면, 지금 나가는 추가 공격에 타수가 바로 더해짐
  4. 추가 공격이 나가기 전에 적이 다 쓰러졌으면 횟수는 저장되고, 다음 발동 때 그 추가 공격의 타수에 더해짐 (웨이브가 바뀌어도 유지)
  5. 추가 공격 도중 적(무적 제외)이 모두 쓰러지면 남은 타수와 관계없이 끝나고, 남은 횟수는 사라짐
- 1스: 공격력 100% 단일
- 2스: 공격력 n%(80%) 광역 (쿨타임 2)
- 3스: 공격력 n%(100%) 광역 + 아군 전체에 **천재의 지원** (피해 증가 30%, 3턴) (쿨타임 4)
  - 천재의 지원은 고유 버프(별도 에셋): 다른 피해 증가 버프와 각각 들어가 합연산으로 더해짐 (예: 추격 20% + 천재의 지원 30% = 50%)
  - 강탈 딜러에게는 새 버프 1개 → 게이지 +30%, 3스 버프 개수 +1 (3턴 안에 다시 걸면 갱신이라 가속 없음)

#### S 하이퍼캐리 딜러 (테스트명 HyperCarry)
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 불굴 (변신 전에만): 치명적인 피해를 받으면 HP 1로 버티고 공격력 비례 보호막(공격력 200%, 2턴). 전투당 1회
- 1스: 공격력 100% 단일
- 2스: 공격력 n%(150%) 광역 + 자신의 3스 쿨타임 n(1)턴 감소 (쿨타임 2)
  - 예: 3스 시작 쿨타임 2 → 첫 턴 2스로 1 감소 → 턴 종료 감소로 0 → 다음 턴 3스(변신) 사용 가능
- 3스: 변신 + 아군 전원 퇴장 + **경계: 고립** 전개 (시작 쿨타임 2, 쿨타임 5)
  - 변신: 1~3스가 변신 스킬로 교체, 엑스트라 턴·종결기 규칙 적용
  - 아군 전원 퇴장: 3스 자체의 효과. 변신이 끝나거나 캐리가 쓰러지면 퇴장 전 게이지 그대로 복귀
  - 경계: 고립(3-12): 공격력 n%(60%), 최대 HP n%(200%), 방어력 n%(30%) 증가 + 행동 제어 면역. 변신이 끝나면 함께 사라짐
    - 버프가 아니라 경계의 효과: 버프 칸을 쓰지 않고, 강탈·소모·만료되지 않으며, 공격력 버프와 중첩 감소도 없이 그대로 더해짐
    - 늘어난 최대 HP만큼 현재 HP도 늘어남
  - 변신 1스: 확산, 메인 대상 공격력 n%(250%) + 양옆 공격력 n%(250%) (쿨타임 0)
  - 변신 2스 **반격 태세** (쿨타임 3)
    - 사용 즉시 태세 진입: 받는 피해 75% 감소
    - **턴 끌어오기**: 전장의 적 전원의 다음 턴을 캐리의 턴 직후로 끌어옴 (편성 순서대로)
      - 끌어온 턴은 적의 실제 정규 턴: AI가 패턴대로 스킬을 고름(보스 강공 포함), 단일·확산 공격은 캐리를 노림
      - 턴 종료 처리(지속피해·남은 턴·쿨타임)와 행동 게이지 리셋도 그대로 → 끌어온 만큼 적의 다음 차례는 뒤로 밀림
      - 1스만 쓰게 하던 이전 방식과 달리 강한 공격을 받아 내 반격을 키우는 구조
    - 끌어온 턴이 모두 끝나면 광역 반격 1회 (추가 공격) → 태세 종료
      - 반격 배율 = 기본 n(150)% + (받은 피해 / 캐리 최대 HP) × n(4) → 공격력 배율. 예: 최대 HP의 50%를 받으면 공격력 150% + 200% = 350%
      - 기본 배율을 둔 이유: 적이 약해 받은 피해가 적어도 반격이 평타(1스 100%)보다 약해지지 않게
      - 받은 피해를 그대로 돌려주지 않는 이유: 적 공격력은 아군 HP 곡선, 적 HP는 아군 공격력 곡선을 따라 커져서 레벨이 오를수록 반격이 적 HP보다 빨리 커짐 (Lv60 테스트에서 보스 3마리 평타 반격 한 번에 보스 HP 70%)
    - 받은 피해는 **피해 감소 적용 전** 값으로 기록 (태세의 75% 감소로 줄어든 피해를 세면 반격이 너무 약해짐). 보호막에 흡수된 양도 포함
    - 반격도 공격이라 피해 증가·치명·방어력이 일반 공격처럼 적용
  - 변신 3스: 공격력 n%(250%) 광역 (쿨타임 2 → 엑스트라 턴 5회 중 최대 3번)
  - 변신 스킬도 쿨타임이 있어 엑스트라 턴 5회 안에서 2~3번씩 돌아감
  - 변신 중에는 원래 스킬 쿨타임이 멈춤 → 3스(변신) 쿨타임 5는 해제된 뒤부터 줄어듦
- 변신 전용 패시브: 스킬(변신 1~3스) 발동 시 최대 HP의 20% 회복. 반격·종결기로는 회복하지 않음
- **변신 중 행동 제어 면역** (경계: 고립의 효과): 기절 등 행동 제어 효과가 걸리지 않음 (현재 행동 제어 = 기절)
  - 혼자 1 대 다를 버티는 구간이라, 기절 한 번에 변신 턴이 날아가지 않게 함 (예: 축적의 수호자 축적 해방)
  - 변신 전에 이미 걸린 기절은 그대로 (변신은 자기 턴에만 하므로 기절 중에는 변신할 수 없음)
- **엑스트라 턴**: 변신 중 캐리가 속도로 차례를 얻으면 정규 턴이 아니라 엑스트라 턴을 받음. 변신 중 최대 n(5)회
  - 차례를 얻는 방식(속도·행동 게이지)은 정규 턴과 같음 → 속도가 빠를수록 적보다 자주 행동
  - 턴이 끝나도 버프·디버프 남은 턴이 줄지 않음 → 퇴장 전에 깔아 준 버프가 변신 내내 유지됨
  - 변신 3스를 쓴 턴도 변신하는 즉시 엑스트라 턴 상태가 되므로 남은 턴이 줄지 않음 (5회 횟수에는 포함하지 않음)
  - 지속피해 발동, 쿨타임 감소, 게이지 리셋은 정규 턴과 같이 진행
  - 3-4의 "추가 턴"(즉시 한 번 더 행동, 지속시간 감소 O)과는 다른 개념
- **변신 종료**: 엑스트라 턴 5회를 다 쓰면 종결기 자동 발동 → 변신 해제·아군 복귀
  - 변신 3스를 쓴 턴은 세지 않음. 반격 태세의 적 공격·반격이 모두 끝난 뒤 종결기가 나감
- **강제 해제**: 변신 중 치명적인 피해를 받으면 사망 대신 변신 상태 최대 HP의 25% 회복 → 종결기 → 변신 해제·아군 복귀
  - 해제 후에도 그 HP 수치를 유지하고, 변신 전 최대 HP를 넘으면 최대 HP로 맞춤
  - 종결기가 나가기 전에 다시 치명적인 피해를 받으면 HP 1로 버팀 (해제 전 사망 방지)
- **종결기**: 변신을 마무리하는 강한 광역 공격 (400%)
- 퇴장한 아군은 반응 패시브가 멈춤. 오라는 퇴장해도 계속 적용됨 (3-7 오라)
- 퇴장한 아군: 공격받지 않고 행동 게이지 전진에서 제외 → 복귀 시 퇴장 전 게이지 그대로 유지. 걸려 있던 버프·디버프와 쿨타임도 유지 (자기 턴이 없으므로 줄지 않음)

#### A 이자 디버퍼 (니콜, 테스트명 CriticalRateBuff)
- **컨셉**: 방어력 감소를 깔아 두면 아군이 때릴 때마다 "이자"가 쌓이고, 2스로 한꺼번에 정산
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 패시브 (이자, 에셋 이름 "여유는 지갑에서"): 방어력 감소가 걸린 적이 아군(니콜 포함)에게 맞을 때마다 이자 1스택 (최대 n(10))
  - 공격 판정마다 쌓임: 광역이면 맞은 대상마다, 추가 공격의 판정도 포함
- 1스: 공격력 100% 단일
- 2스 (빌린 돈은 빠르게 갚으라구): 적 전체 공격력 n%(200%) + 이자 1스택당 n%(20%) → 이자 전부 소모, 이후 방어력 감소 부여 (쿨타임 3)
- 3스 (특대서비스): 아군 전체 치명 확률 증가·가속 → **2스를 함께 사용** (2스 쿨타임은 돌지 않음) (쿨타임 5)

## 5. 성장

- **캐릭터 레벨 + 무기 레벨**만 구현. 장비는 시간이 남으면 추가
- 최대 레벨 60, 진급 5회 (10·20·30·40·50레벨). 레벨당 선형 성장 + 진급 시 점프 (젠존제 구조 참고)
  - 점프는 **진급 버튼을 누른 순간** 붙는다 (Lv10·진급 전 < Lv10·진급 후). 예: S급 균형형 공격력 Lv10 201.8 → 진급 241.7, HP 1,339 → 1,750
  - 적은 진급이 없으므로 그 레벨까지 진급을 마친 기준으로 계산 (Lv10 적 = 진급 1회)
- S급 균형형 Lv60 기준: HP 7500 / 공격력 800 / 방어력 600 (무기 제외)
- 직군 차이는 주로 공격력으로 냄 (보정 폭 0.9~1.15), A급 = S급 × 0.9
- 무기: 공격력·HP·방어력 기초 스탯만 제공, 캐릭터와 같은 진급 구조
  - **종류 4개 = 낄 수 있는 직군**: 칼 = 공격, 방패 = 방어, 마법지팡이 = 지원, 로자리오 = 회복. 캐릭터 한 명은 무기 하나, 무기 하나는 한 명
  - 종류마다 3·4·5성 하나씩 12종: 칼(철검·서리 대검·칼리번), 방패(강철 방패·수호자의 방패·아이아스), 마법지팡이(견습 지팡이·별빛 지팡이·꽃의 지팡이), 로자리오(나무 로자리오·은빛 로자리오·성자의 로자리오)
  - 아이템 이름·설명(플레이버 텍스트)은 사용자가 직접 씀. 새 아이템을 만들 때는 설명을 비워 둠
  - 풀 육성(Lv60·진급 5회) 스탯: 공격력 3성 400 / 4성 500 / 5성 700, HP 480 / 600 / 840, 방어력 48 / 60 / 84 (종류와 무관하게 등급만으로 차등)
  - 레벨별 스탯 = 풀 육성 스탯 × 비율. Lv1 = 16%, 이후 캐릭터와 같은 모양(레벨당 + 진급 점프)으로 100%까지
  - **성장**: 캐릭터와 같은 육성 창·같은 경험치 곡선(Lv1 → 60 = 900,000). 재료는 무기 강화석 1개 4,500 → **200개로 Lv60**. 10레벨마다 진급(지금은 무료), 초과 경험치는 버림
    - 진급 재료 = **무기 개조 키트**: 진급 1~5회째에 1 / 2 / 4 / 6 / 10개 (합 23, 임시)
    - 지금은 디버그로 강화석·무기 개조 키트 무한 (`WeaponGrowthRules`에서 끔)
- PvP 없음 → 밸런스는 적 스탯으로 맞춤
- **경험치** (StatTable "경험치" 시트가 기준): Lv1 → 60 총 900,000 = 고급 경험치 재료(3,000) 300개
  - 구간별: 1~10 6,000(가정) / 10~20 24,000 / 20~30 60,000 / 30~40 135,000 / 40~50 225,000 / 50~60 450,000 (마지막 10레벨이 절반)
  - 경험치 재료 3종: 초급 300 / 중급 1,000 / 고급 3,000 (초급·중급 수치는 임시)
  - 진급하지 않으면 레벨 상한(10·20·30·40·50)에서 멈춤. 상한을 넘는 경험치는 버림
  - 지금은 디버그로 재료 무한 (보유하지 않아도 쓰고 줄지 않음, `GrowthRules`에서 끔). 재화 던전이 생기면 끔 (진급 재료도 같은 설정을 따름)
  - **진급 재료 = 진급 휘장**: 진급 1~5회째(Lv10·20·30·40·50)에 2 / 4 / 8 / 12 / 20개 (합 46, 임시). 무기는 무기 개조 키트로 캐릭터의 약 절반
- **전투 레벨 적용 (현재 구현, 성장 시스템 전 임시)**
  - 캐릭터 데이터의 스탯은 **Lv1 값**으로 보고, S급 균형형 성장 곡선(Lv1 → 그 레벨·진급 횟수)의 비율만큼 키운다
    - 로비에서 시작한 전투는 세이브의 실제 진급 횟수, 전투 씬을 바로 실행한 테스트는 그 레벨까지 진급을 마친 것으로 봄
    - 예: Lv60 아군 → HP·방어력 ×12.5, 공격력 ×6.15 (균형형 600→7500, 130→800, 48→600)
    - 캐릭터마다 다른 수치(직군·등급 차이)는 레벨이 올라도 같은 비율로 유지됨
  - 적은 6장 역산 기준을 따라 **곡선을 교차**해 키운다: 적 HP는 아군 공격력 곡선, 적 공격력은 아군 HP 곡선, 방어력은 방어력 곡선
    - 이유: 적 HP는 "아군 몇 방에 죽는지", 적 공격력은 "아군 HP 몇 %를 깎는지"로 정하므로 (StatTable 적 스탯 시트와 같은 비율)
  - 장착 무기 스탯은 기본 스탯에 더해짐 (공격력 % 버프가 무기 몫까지 키움). 로비에서 시작한 전투만 (씬을 바로 실행하면 무기 없음)
  - 전투 씬의 BattleManager에서 아군 레벨·적 레벨을 따로 정함 (플레이 전에 설정)

## 6. 스테이지와 적

- **기본 스테이지 7개**: 권장 레벨 1 / 10 / 20 / 30 / 40 / 50 / 60, 2웨이브
- **보스 스테이지 3개** (Lv60): 파티 컨셉별로 유리한 보스 (캐릭터 접대 콘텐츠, 포폴 핵심 포인트)
  - 원칙: 유리한 파티가 있을 뿐, 다른 파티로도 공략은 가능해야 함
    - 검토 중: 보스 3을 유리한 파티 사실상 필수로 둘지, 다른 파티도 깰 수 있게 둘지 (후보: 자폭 위력을 부하 남은 HP에 비례, 별 미션으로 유리한 파티 보상)

### 보스 1: 축적의 수호자 (가칭, 강탈 파티용)
- 구성 (편성 순서): 버프몹 1 · 보스 · 버프몹 2, 전원 Lv60 (지금은 `Stage_BuffEnemy` 2웨이브에 배치. `Stage_Boss1`은 테스트용 스테이지로 쓰는 중)
  - **버프몹은 무적**: 피해를 받지 않아 죽일 수 없음. **보스만 쓰러뜨리면 클리어**
  - 버프몹 1·2 (둘 다 공세의 사도, 속도 100): 매 턴 보스에게 **공세** 1개
    - 공세 = 적 전용 중첩 버프: 1개당 공격력 n(20)%, 3턴, 걸 때마다 새 칸 (버프 칸 10개가 상한). 아이콘은 광폭과 같은 대검
    - 한 턴에 거는 개수는 테스트로 결정 (2개면 보스 3번째 턴, 3개면 2번째 턴에 축적 해방)
    - 가호의 사도(소생·가속)는 빠짐. 광폭·경화는 일반 스테이지 버프몹이 그대로 씀
- 보스 (속도 90): 공세 개수에 따라 행동이 바뀜
  - 패시브 (축적의 갑주, 임시명): 자신에게 걸린 버프 1개당 주는 피해 n(10)% + 피해 감소 n(10)% (버프 10개면 피해 +100%, 피해 감소는 상한 75%)
    - 버프 칸 밖의 상시 효과라 강탈되지 않음. 강탈 파티는 버프를 뺏는 것만으로 보스가 약해짐
  - 0~3스택: 단일 공격 (100%)
  - 4~9스택: 광역 공격 (n(80)%)
  - 속도를 110 → 90으로 낮춤 (플레이 테스트): 보스가 빠르면 강탈 딜러가 강탈할 틈 없이 축적 해방이 나가는 구간이 생김
  - 강탈 딜러(속도 100, 플레이 테스트로 115에서 낮춤)가 보스 1턴당 약 1.1턴(+ 버프 가속)을 받아, "버프가 차기 전에 뺏는다"는 공략이 성립하는 속도
- **축적 해방**: 자기 턴이 올 때 공세가 10개면 버프 전부 해제 + 아군 전체에 **공격력 n(100)% + 최대 HP n(90)%** 피해 (기절 없음)
  - 버프를 해제하므로 연달아 쓰지 않고, 다시 10개가 쌓여야 다음 축적 해방
  - 바꾼 이유: 예전(버프 4개 → 즉사기)은 강탈 딜러가 1스만 쓸 수 있는 턴과 보스 턴이 겹치면 바로 전멸하는 양자택일 구조라, 강탈 타이밍이 꼬이면 강탈 파티도 깨기 어려웠음
    - 공세는 갈수록 보스를 세게 만들어(공격력·광역 전환) 놓쳐도 점점 아파질 뿐이고, 해방까지 여유가 있음
- 강탈 파티: 공세를 뺏어 해방을 막고, 뺏은 개수만큼 새 버프라 게이지·3스가 크게 강해짐 (대신 세베리안 버프 칸이 넘치면 아군 버프가 밀려날 수 있음)
- 다른 파티: 버프몹을 잡을 수 없으므로 축적 해방 전에 보스를 빨리 깎거나, 맞고 버티는 방식으로 공략 (테스트하며 확인)
- 하이퍼캐리 광역기로 잡몹을 정리해 쉬워지는 문제는 버프몹 무적으로 해소
- 보스 HP: Lv1 12,500 (엑셀 보스 기준 4,986의 약 2.5배, 플레이 테스트로 올림)
  - 이유: 전투가 길어질수록 버프를 못 뺏는 파티는 공세가 쌓인 보스와 축적 해방을 더 많이 맞음 → 강탈 파티가 확실히 유리해지도록
  - 강탈 파티는 뺏은 버프로 3스가 강해져 HP가 늘어도 짧게 끝냄 (풀버프 3스 한 방 ≈ 보스 HP 약 30%)
- 수치 전부 임시 (공격력은 엑셀 보스 기준, 공세 수치·광역 배율·축적 해방 배율은 테스트로 조정)

### 보스 2: 갑각의 거체 (가칭, 지속피해 파티용, 스테이지 에셋 `Stage_Boss2`)
- 구성 (Lv60, 2웨이브): 1웨이브 잡몹 2 + 정예 1 / 2웨이브 보스 단독
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 보스 (속도 n(95), Lv1 HP n(25,000) = 다른 보스 스테이지 보스의 2배)
  - 패시브 (굶주린 재생, 임시명): 디버프가 2개 미만인 동안 속도 증가 (% 보정·고정 보정 둘 다 쓸 수 있음, 수치 미정)
    - 지속피해를 꾸준히 2개 이상 깔아 두면 보스가 느려짐 → 지속피해 파티 접대
  - **디버프가 없는 턴**: 행동할 차례에 자신에게 디버프가 하나도 없으면 아군 전체에 **공격력 n(100)% + 최대 HP n(40)%** 피해
    - 최대 HP 몫은 공격력·치명·방어력과 무관. 공격력 몫은 일반 공격과 같음. 받는 피해 증가·피해 감소·보호막은 둘 다 적용
    - 공격력 몫을 넣은 이유: 최대 HP 몫만 있으면 레벨이 낮은 아군도 한 대에 쓰러지지 않음 → 레벨 차이만큼 공격력 몫이 커지게 함
  - 디버프가 있으면: 광역 150% (시작 쿨타임 2, 쿨타임 3)가 준비됐으면 광역, 아니면 단일 100%
- 지속피해 파티: 화상·독을 늘 깔아 두므로 40% 공격을 피하고, 높은 HP를 지속피해로 깎음
- 다른 파티: 디버퍼(니콜 방어력 감소 등)로 디버프를 끊기지 않게 하거나, 맞으면서 회복·보호막으로 버팀
- 피격 무효(자기 턴마다 4회 충전, 피해만 0)는 효과 블록으로 남겨 두고 이 보스에서는 쓰지 않음
- 디버프 조건이 "아무 디버프"인지 "화상·독만"인지는 테스트하며 결정 (지금은 아무 디버프)

### 보스 3: 군단 지휘관 (가칭, 하이퍼캐리 파티용, 스테이지 에셋 `Stage_Boss3`)
- 구성 (Lv60, 2웨이브): 1웨이브 잡몹 2 + 정예 1 / 2웨이브 군단 지휘관 + 시작 부하 2마리. **보스만 쓰러뜨리면 클리어** (부하는 승리 조건에서 빠짐)
- 수치는 전부 임시 (괄호 안이 현재 테스트 값)
- 보스 (속도 100, Lv1 HP n(12,500) = 테스트 보스의 약 2.5배)
  - 등장 시 (군단 집결): 부하 2마리를 데리고 등장 (소환한 부하로 취급 → 피해 감소·최대 수·함께 퇴장 규칙 그대로)
  - 부하 소환: 두 번째 자기 턴부터 자기 턴 2번마다(시작 쿨타임 1, 쿨타임 2) 부하 2마리 소환. 보스가 소환한 부하는 전장에 **최대 4마리** (화면에 보스 포함 5명)
    - 부하가 4마리면 소환하지 않고 단일 공격 (100%)
    - 부하는 보스의 왼쪽·오른쪽에 번갈아 서서 보스가 가운데에 남음
  - 패시브 (지휘): 부하가 한 마리라도 있는 동안 받는 피해 50% 감소 (부하 수와 무관, 버프 칸이 아니라 강탈되지 않음, 머리 위 "지휘" 아이콘)
    - 대상 쪽 보정이라 지속피해도 반감 → 지속피해 파티에 불리
  - 보스가 쓰러지면 남은 부하도 함께 퇴장
- 부하 (자폭병, 속도 105, Lv1 HP n(1,000) = 잡몹의 약 4배, 정예와 비슷)
  - 자기 첫 턴: 아군 1명 단일 공격 (100%)
  - 자기 두 번째 턴: **자폭** = 아군 전체 공격력 n%(600%) + 기절 1턴 → 사라짐
    - Lv60 기준 평균 아군 HP의 약 60% (두 마리가 같이 터지면 보호막 없는 아군은 쓰러짐) → 부하를 먼저 잡게 만드는 압박
    - 300%(약 30%)일 때는 탱커 보호막·면역만으로 맞으면서 깰 수 있어 올림 (플레이 테스트)
  - 머리 위 "자폭 준비" 아이콘에 남은 턴 표시 (자기 턴 기준)
  - 자폭으로 사라지는 것은 처치가 아님 → 강탈 딜러 추격 같은 처치 반응 없음. 아군이 쓰러뜨리면 일반 처치
- 하이퍼캐리: 광역기로 부하를 정리하고, 변신 중에는 고립 경계로 기절 면역 + 아군 퇴장이라 자폭을 혼자 받음. 부하가 많을수록 반격 태세로 끌어오는 턴이 늘어 반격이 커짐
- 다른 파티: 부하를 2턴 안에 잡지 못하면 광역 + 기절을 맞음. 탱커 면역(기절)·돌파 딜러(부하마다 50% 돌파)로 대응 가능
- **목표 전투 시간**: 2웨이브 기준 약 3분 (행동 1회 약 5초 가정, 웨이브당 아군 행동 약 9회)
- **적 스탯 역산 기준**: 권장 레벨의 기대 아군(진급 완료, 3성 무기, 공격형 딜러 단일기, 치명 제외)
  | 등급 | 처치에 필요한 공격 | 적 1회 공격 피해 (아군 HP 대비) |
  |---|---|---|
  | 잡몹 | 1방 | 10% |
  | 정예 | 4~5방 | 17.5% |
  | 보스 | 약 20방 | 30% (광역기는 더 낮게) |
- 전투 시간은 잡몹이 아니라 정예·보스가 담당 → 웨이브에 정예를 섞어 3분을 맞춤
- 보스 처치 타수(20방)의 체감 확인용 기준: Lv60 강탈 딜러 풀버프 3스(버프 8개, 3성 무기, 확정 치명) 한 방이 보스 HP의 약 80%
  - 3분의 1로 하려면 보스 HP 약 2.5배(기본 스킬 약 50방)가 필요 → 보스 스테이지 보스(축적의 수호자·군단 지휘관)는 2.5배(Lv1 12,500)로 적용, 기본 스테이지 보스는 그대로
- 스테이지별 웨이브 구성은 스테이지 에셋(`Data/Stages/`)에서 정한다. 테스트용 `Stage_BuffEnemy`(축적의 던전) = 1웨이브 잡몹 2 + 정예 1 / 2웨이브 잡몹 2 + 보스 1 (버프몹은 무적)
- 테스트 적 데이터는 StatTable 적 스탯 시트의 등급별 Lv1 값을 쓴다 (레벨은 적 성장 배율로 키움)
  | 테스트 적 | 등급 | Lv1 HP / 공격력 / 방어력 / 속도 |
  |---|---|---|
  | Enemy_Buffer, Enemy_Slow | 잡몹 | 248 / 99 / 48 / 110, 90 |
  | Enemy_Healer (적 전체에 소생·가속) | 잡몹 | 248 / 99 / 48 / 105 |
  | Enemy_Test | 정예 | 1117 / 173 / 48 / 100 |
  | Enemy_Boss | 보스 | 4986 / 296 / 48 / 110 (Lv60 30,680 / 3,704 / 600을 역산) |
- 기본 스테이지 웨이브 구성: 1웨이브 잡몹 2 + 정예 1 / 2웨이브 잡몹 2 + 스테이지 보스 1
  - 스테이지 보스는 보스 스테이지 보스보다 약하게 (처치 타수는 테스트로 결정, 3분 목표 기준)
- 별 미션: 스테이지당 3개 (사이클 제한 등)

## 7. 가챠

### 7-1. 규칙
- 기본 확률: S 0.6% / A 9% / 5성 무기 1% / 4성 무기 10% / 3성 무기 79.4%
  - 무기 구간은 캐릭터 구간(S·A) 뒤에 붙어 있어 캐릭터 확률·천장·A 확정은 그대로. 무기에는 천장이 없음
  - 4·5성 무기도 캐릭터 카운터(S 천장·A 확정)를 1씩 올림 (3성 무기와 같음). "A 확정"은 A 캐릭터만
  - 시뮬레이션 100만 회: S 1.63%(변화 없음) / 5성 무기 0.95% / 4성 무기 9.4% (소프트 천장·A 확정 차례에는 그 자리가 캐릭터라 공칭보다 조금 낮음)
- A 확정: 단차·10연차와 무관하게 누적 10회마다 A 1개 확정
  - 10회를 채우기 전에 S가 나오면 A 확정을 채운 것으로 보고 카운터를 0으로 되돌림 ("10회 안에 A 이상 1개"와 같음)
- A는 픽업 없이 보유 가능한 A 캐릭터 중 균등 랜덤
- S 천장: 90회째 S 확정
- 소프트 천장: 71회부터 매 회 +4%p (임시값)
  - 71회 4.6% → 72회 8.6% → … → 89회 76.6% → 90회 100%
- 반천: S가 픽업이 아니면 다음 S는 픽업 확정 (픽업 최악 180회)
- 천장 카운터와 픽업 확정 여부는 다음 픽업 배너로 이월

### 7-2. 계산 결과 (소프트 천장 +4%p 기준)
| 항목 | 값 |
|---|---|
| S 1개 평균 | 약 61회 |
| S 최종 획득 확률 (공시용) | 약 1.64% |
| 픽업 1개 평균 | 약 92회 |
| 70회 이내 S 획득 | 약 34% |
| 71~80회 S 획득 | 약 61% |

| 누적 뽑기 | 픽업 획득 확률 |
|---|---|
| 90 (무료 재화 총량) | 약 60% |
| 104 (무료 + 월정액 14뽑) | 약 66% |
| 120 | 약 71% |
| 150 | 약 87% |
| 180 | 100% |

### 7-3. 설계 의도
- 90 확천은 안전망, 체감 천장은 80 전후
- 무료 재화 총량(90뽑)을 픽업 기댓값(약 92뽑)에 맞춰, 평균적인 무료 유저가 픽업 1개를 얻도록 설계
- 월정액만으로는 픽업 확정이 안 됨 → 확정을 원하면 추가 과금 필요 (호요버스식 구조)
- 지속피해 파티는 A 비중이 높아 무과금도 맞추기 쉬운 파티, 강탈 파티는 S가 많이 필요한 고점 파티

### 7-4. 획득 처리와 연출 (현재 구현)
- 배너당 픽업은 S 1명. 픽업이 아닌 S는 나머지 S 중 균등 랜덤
- 등급 표시: 3성 = 3성 무기(파랑), 4성 = A 캐릭터·4성 무기(보라), 5성 = S 캐릭터·5성 무기(황금빛). 4·5성 무기도 캐릭터와 같은 빛 연출(물레 색, 차오르는 빛, 반전)
- 무기는 그 등급 무기 중 균등 랜덤으로 1개를 얻어 무기 인벤에 저장 (칸이 꽉 찼으면 3성만 자동 분해, 2장 인벤토리)
- 중복 캐릭터는 지금은 아무 효과 없음. 새로 얻은 캐릭터는 Lv1·진급 0회로 지급 (전투원 화면에서 육성)
- 뽑은 직후 저장 (카운터·보유 캐릭터·보석). 연출을 SKIP하거나 도중에 꺼도 결과는 같음
- 검증: 100만 회 시뮬레이션에서 S 1.63% (평균 61.4회), 픽업 평균 91.3회, 90회 이내 60.1%, 104회 이내 65.7%, 최악 168회 → 7-2 계산과 일치
- **연출 순서**
  1. 물레 (3D 모델, 나무·황동 재질과 조명): 화면의 물레 바퀴를 잡고 시계 방향으로 돌림. 바퀴와 실감개를 잇는 줄 가운데의 빛이 점점 커지며 파랑 → 보라 → 황금빛으로 바뀌고, 이번 결과의 최고 등급 색까지만 바뀜
     - 바퀴는 돌릴수록 테두리에 은은한 고리 빛이 생기고 조금씩 밝아짐 (등급과 무관한 따뜻한 색). 다 돌리면 줄 가운데에서 등급 색으로 터짐
  2. 한 장씩 공개 (탭하면 다음 장). 화면 바닥은 평소엔 어둡고, 카드마다 그 등급 색(파랑·보라·황금빛)으로 빛이 피어오름 (반전이면 보라 → 황금빛)
     - 3성: 파란 카드에 칼이 바로 보임
     - 4성: 카드 아래에서 보라 빛이 차오르다 터지며 캐릭터 공개
     - 5성: 황금빛으로 4성보다 오래 뜸 들이다 더 크게 터지며 공개
  3. 결과 목록: 세로로 긴 카드 10장을 한 줄로 나열해 한꺼번에 보여주고 확인으로 닫음 (캐릭터는 일러스트가 카드를 채움)
  - **반전**: 5성이 있어도 30% 확률로 물레 줄 빛은 보라까지만 바뀜 → 공개 때 보라 빛이 카드가 흔들리며 황금빛으로 바뀐 뒤 5성 공개 (결과는 이미 정해져 있고 연출만 다름)
  - SKIP은 언제든 결과 목록으로. 연출 중 탭하면 남은 대기를 건너뜀
  - 빛·불꽃은 파티클 + Bloom 글로우 (물레 테두리 고리 빛, 줄 가운데 빛·불꽃, 카드 아래 차오르는 빛, 섬광·고리·불꽃·광선이 터지는 빛)

- 획득처별 분배표는 스테이지 구성(기본 7 + 보스 3) 기준으로 재작성 필요

## 9. 데이터와 저장

- **고정 데이터 = ScriptableObject**, **세이브 = JSON** (Newtonsoft Json, `Application.persistentDataPath`)
- SO는 런타임에 수정하지 않음. 세이브에는 ID와 바뀌는 값만 저장하고, 불러올 때 ID로 SO를 찾아 연결
- 저장 시점: 가챠·레벨업·스테이지 클리어 직후 즉시 저장
- 파일 깨짐 방지: 임시 파일에 먼저 쓰고 완료되면 원본과 교체
- 세이브에 `version` 필드를 두어 구조 변경 시 변환
- 세이브 항목
  - 재화
  - 보유 캐릭터 (ID, 레벨, 진급)
  - 보유 무기 (개체 고유 ID, 무기 ID, 레벨, 진급, 장착 캐릭터)
  - 가챠: S 천장 카운터(0~89), 픽업 확정 여부, 10회 A 확정 카운터(0~9)
  - 스테이지 클리어·별 미션 기록, 편성
- **현재 구현**
  - 저장 항목: 재화, 보유 캐릭터, 가챠 카운터, 스테이지 클리어, 편성, 무기 인벤(개체 번호·무기 ID·레벨·진급·장착 캐릭터), 재료 인벤(ID·개수) (별 미션은 해당 시스템을 만들 때 추가)
  - 세이브 버전 2: 인벤토리 추가. 버전 1 세이브는 빈 인벤토리로 변환
  - 세이브 버전 3: 캐릭터 경험치 추가. 진급 기능 전에 Lv60으로 받은 캐릭터는 불러올 때 레벨에 맞는 진급 횟수(Lv60 = 5회)로 보정
  - 세이브 버전 4: 무기 경험치 추가. 무기 ID는 그대로라 기존 창·활은 방패·지팡이로 바뀌어 보임
  - 세이브 버전 5: 편성을 팀 4개(팀 이름 + 칸)와 고른 팀 번호로 바꿈. 예전 편성은 1팀으로 옮김
  - 저장 시점에 레벨업·진급 추가
  - 저장 시점: 편성 변경·팀 선택·팀 이름 변경, 로비에서 시작한 전투의 승리(스테이지 클리어). 씬을 바로 실행한 테스트 전투는 기록하지 않음
  - **새 게임**: 세이브가 없으면 하이퍼캐리 Lv1 1명을 보유하고 편성한 상태로 시작 (`GameDatabase`에서 변경)
  - 세이브 파일이 깨졌으면 `.broken`으로 따로 보관하고 새 게임으로 시작
  - 에디터 메뉴 Tools > Save: 세이브 삭제(새 게임), 세이브 폴더 열기 / Tools > Inventory: 테스트 아이템 지급, 무기 칸 가득 채우기 / Tools > Growth: 보유 캐릭터 전부 Lv1로 (레벨업·진급 시험용)

## 10. 미정 목록

### 전투
- 방어력 관통 (구현 시기와 상한)
- 캐릭터별 치명 수치, 스킬 수치(n%), 나머지 7명의 스킬 상세

### 콘텐츠
- 보스 1의 하이퍼캐리 대응 문제 (6장 참고)
- 별 미션 조건

### 가챠·성장
- 상시 배너 유무
- 중복 캐릭터 처리 (돌파 / 재화 변환)
- 진급 휘장·무기 개조 키트·강화석 획득처(분해 외), 종류별 스탯 차이(방패 방어력↑ 등) 여부
- 진급 재료 수량 확정 (지금 임시: 캐릭터 2·4·8·12·20, 무기 1·2·4·6·10), 진급에 골드도 쓸지

- 무료 재화 분배표 재작성, 스태미나 유무, 월정액 상품 구성

## 11. 보류 아이디어

> 확정이 아니다. 핵심 캐릭터·보스 구현 뒤 최소 프로토타입으로 플레이해 보고 도입 여부를 정한다.

### 존(Zone) 시스템
- **컨셉**: 메인딜러가 각성 상태에 들어가 연격을 이어가는 순간 (흑섬 느낌). 게임 고유의 재미 요소 후보
- **공통 규칙 (1차안)**
  - 진입 즉시 추가 턴, 쿨타임 초기화
  - 존 3턴 (정규 턴 + 추가 턴 합산). 존 동안 버프·디버프 지속시간이 줄지 않음
  - 종료 후 탈진: 속도 감소 + 행동 당기기 무효 (마지막 존 턴에 미뤄둔 당기기는 탈진 전에 적용)
  - 진입 방식: 확률 + 천장은 "원하는 타이밍에 못 터뜨려 리트"를 부르므로, **확정 게이지 + 발동 타이밍은 플레이어가 선택** 방향 (게이지가 덜 찼을 때 낮은 확률의 조기 진입으로 흑섬 느낌 보완). 충전 조건 미정
  - 대상: 메인딜러 전용. 지원·회복·방어 직군은 존이 없음 (존 보조 역할로 확장 여지)
- **딜러별 연격 (1차안)**: 공통 문법은 "처치하면 다음 대상으로 이어진다"
  - 강탈 딜러: 3스 강화, 버프 소모 없음. 처치 못 하면 3스 초기화 + 행동 게이지 50%, 처치하면 추가 공격으로 다른 대상에게 3스 (최대 2회)
  - 격발 딜러: 존 동안 패시브 화상 2개. 3스로 처치하면 죽은 적의 지속피해를 다음 적에게 옮기고(격발 없이) 추가 턴 + 3스 쿨타임 초기화
  - 하이퍼캐리: 변신 중에도 존 사용 가능. 존 추가 턴은 변신 3턴 제한에 포함하지 않아 1 대 다 구간이 늘어남 (최대 6행동). 후보: 반격으로 처치 시 추가 턴
- **보류 이유**: 각 딜러가 이미 자기 절정(강탈 3스, 격발, 변신)을 갖고 있어, 존이 새 재미인지 기존 절정을 키우는 것뿐인지 불분명. 딜러별 예외가 늘어 설명이 길어짐
- **검증 계획**: 딜러별 효과 없이 공통 규칙만 강탈 딜러에 붙여 플레이 → 신나면 확장, 밋밋하거나 기존 순환을 망치면 폐기
